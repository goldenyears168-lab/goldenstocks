# XS 選股腳本（XQ 全球贏家）

盤後選股規則的 XS 版本：`GS*` 是權證小哥／`chip_sop` 規則，`A*` 是由 XQ 官方預設腳本改寫的專家策略。
官方預設腳本庫：`sysjust-xq/XScript_Preset`（XQ 說明該庫供用戶作範例與修改；本次參考版本 `d15a4157cc`，完整下載放在 `${GOLDENSTOCKS_DATA_DIR}/research/xq_preset/`，不進 git）。

## 狀態
- **尚未在 XQ 編輯器編譯**（這邊沒有 XS 編譯器）。`tests/test_xs_scripts.py` 只做靜態檢查（括號、引號、begin/end、分號、outputfield 編號與標準欄）。
- 語法與欄位名稱都取自 XQ 官方文件、官方預設腳本、與編輯器「插入欄位」畫面；已在編輯器編譯通過的範例：2026-10-25 的欄位對帳腳本（12 個欄位全數存在）。
- 欄位頻率：日頻腳本裡的週頻欄位（大戶持股比例、總持股人數）用 `GetField(..., "W")[k]` 取前 k 週（`lesson/xspractice/取得資料欄位時的「對位問題」`）。

## 用法
1. 編輯器 → 檔案 → 開啟 `.xs`（或貼上內容）→ 按「編譯」。
2. 「加入選股」→ 選股中心 → 範圍選「普通股全部」→ 執行；回溯日期可用選股結果區的「回溯功能列」。
3. 想每天自動跑：選股中心對該策略按「每日自動執行」；**資料更新時間**（XQ 公布）：主力 19:00、三大法人 19:30、信用交易 22:30 → 含融資券的腳本請在 22:30 後取結果。
4. 選股結果區的「匯出」可匯出整份清單成 Excel；用 `scripts/research/xq_reconcile.py` 與我們 DB 對帳。

## 標準輸出欄（所有腳本共用，順序勿改）
1 收盤、2 漲跌幅%、3 量比（今日量÷前20日均量）、4 前20日均量、5 前20日均成交值(億)、6 主力集中度1日%、7 主力集中度5日%、8 流動性閘門(1=通過)；9 以後為各腳本自己的欄位。

## 流動性閘門（v2 起，所有選股類腳本預設套用）
前20日均量 ≥1000 張，且前20日均成交值 ≥0.5 億，且收盤 ≥10 元；三個數字都是腳本的 input，可在選股中心調。
依據：2026-10-22 全市場約 1,959 檔，20 日均量中位數 281 張、均成交值中位數 0.13 億；本閘門約留 27%。專案內既有先例：/inventory 20 日均成交值 ≥3000 萬、xiaoge_chip_daily ≥5000 萬、R27 量小 3000 張（只標示）。
事件與風險清單（GS14 處置中、GS15 庫藏股）預設不套閘門，旗標仍輸出在第 8 欄。

## 證據分級（每支腳本檔頭都有）
T0＝無專屬檢定（描述）；T2＝有檢定但結果混合；T3＝有檢定且不支持或無預測力；TX＝XQ 作者自述未驗證；E＝事件或風險清單（非方向）。
本專案對這批規則沒有任何一條有「樣本外有 edge」的檢定結論；清單的用途是縮小候選與標示風險，不是訊號。
