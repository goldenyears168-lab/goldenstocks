# 小哥知識書：未單純相信段落盤點

對象：`docs/warrant-xiaoge/knowledge-book.md`（行號以盤點當時為準）。
目的：依「先相信小哥、先照做」的新方針，列出書中所有沒有單純相信的段落，並寫明改成先相信的處理。

## 摘要

- 總件數：169 件（第十一章 1654-2174 為標題層清單，整體各記一筆、不逐條）。
- 各類型件數：待核與不足 56、我們的檢定結果 36、證據層級標記 23、質疑小哥宣稱 17、對照其他派別 14、批判性措辭 12、其他 11
- 最集中的章節：第十二章「讀法與紀律／本 repo 檢定對照」（約 2175-2271）加上第十三章（2275-2356）與附錄 D／E（2500-2609），合計 73 件，幾乎全是「我們的檢定結果」與「質疑小哥宣稱」。其次是第三章策略 S1-S28（338-948，41 件，以「待挖／程式化」缺口語氣與 repo 檢定框為主）、第十章規則庫（1523-1646，14 件，「本 repo 檢定」欄為主）。
- 全書共通的不信任手法有三種：每個論點掛證據層級標籤、每招後附「程式化／待挖」缺口、每招後附本 repo 的檢定框並下「不支持／不足」判決。
