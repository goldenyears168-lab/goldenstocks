## 名稱對照 repo 的限制

- 對照表來源：`stock_broker_branch_daily` 的 `securities_trader_id`／`securities_trader`，唯讀；因全表去重掃描過慢，改取多個抽樣日（2026-03-16、06-15、08-14、09-15、10-15）加部分全表掃描，共約 1,007 個 id。已退出或極少出現的分點可能不在內。

- exact＝去除上述差異後名稱完全一致；candidate＝同券商、名稱部分相同；none＝無對應（若有同地名他家分點，會在備註列出但不當作對應）；category＝地緣群或泛稱。
- 券商層級的條目（如 元大、凱基）對到的是該券商的總公司／券商代號，不是任何單一分點。
- 字幕為語音自動轉寫，同音錯字很多（例：管錢→館前、藍屯→南屯、原富→元富）；別名合併是依上下文與其他出處的寫法，無法確認的保留原轉錄名並列入待聽音。
- 同名分點在 repo 以 id 區分；本名單的 repo 欄只作名稱對照，不代表小哥指的就是該 id 當時的分點。
