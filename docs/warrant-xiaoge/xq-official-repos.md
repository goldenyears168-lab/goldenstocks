## XQ 有、小哥書中幾乎沒有（新觀念）
- 自營商『避險』與『自行買賣』拆開（小哥只用權證『自營比』）。
- 控盤者主動買盤／賣盤：系統統計券商分點成交值>100 萬、價位高於昨收或開盤者為主動買盤（書中『控盤者』僅 3 處）。
- 實戶、籌碼鎖定率、實質買賣盤比、收集派發指標（分公司賣出家數−買進家數）、買家數／賣家數、官股券商買賣超（書中 0～2 處）。
- 把慣性做成標準模板：『連續 N 期…都大於 X』『近 N 期至少 M 期…』『近 N 期合計佔成交量 X%』——小哥是口語描述（連買、一買一賣），XQ 是可回測的參數化條件。
- 財務面 2,073 個條件（小哥偏重營收與殖利率）、自動交易 `SetPosition` 與安控。
