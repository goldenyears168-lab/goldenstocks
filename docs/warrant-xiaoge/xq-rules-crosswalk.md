# XQ（嘉實 XQ 全球贏家）教學內容與內建選股條件，對照小哥規則

查證日：2026-10-24。來源為公開網頁搜尋與 XQ 官方論壇（見文末）；**搜尋沒找到** XQ「周轉率」「連續漲停」「分點」的內建條件頁，這些標「未查到」，不是「不存在」。

## 一、小哥書中與 XQ 的關係
書中只有一處提到 XQ（`xiaoge-book-vol3-lives.md` 約 1213 行）：小哥用 XQ 在走勢圖按右鍵→繪圖，畫出他的打單點位圖。**書中沒有任何 XQ 選股或警示腳本。**

## 二、XQ 教學／官方論壇確認到的內容
1. **贏家選股**：台股模組提供價量、籌碼、財務等約 300 種選股策略，可自訂 100 組並回測勝率；平台約 900 個資料欄位（基本面、技術面、財務面、籌碼面）。另有「大戶買賣力」盤中觀察大戶方向。
2. **主力買賣超**：官方部落格示範在選股中心設定「近 N 日主力買超張數超過門檻」（例：3 日主力買超量）。
3. **布林帶寬選股腳本（XQ 小幫手）**：
   - 上軌 `bollingerband(Close, 20, 2)`、下軌 `bollingerband(Close, 20, -2)`、中軌 `average(close, 20)`。
   - 帶寬 = `100 * (up - down) / mid`，mid = (up + down) / 2。
   - 條件：`close < up and close > midband and bbandwidth < 10` → 帶寬 <10% 且收盤在中軌與上軌之間（初版漏了中軌，後修正）。
   - 另一則建議：「通道震幅」= 上軌÷下軌−1 再 ×100。
4. **盤末開布林警示腳本（使用者貼、小編回覆，2024/03/08）**：12:00–12:30、每 5 分鐘跑一次；條件＝①價格≥日線布林上軌 ②預估量≥昨量或 5 日均量的 1.68 倍 ③月線（20 日均）上升。小編提醒：5 分 K 上算的斜率不是日線斜率（`LinearRegSlope` 沒有跨頻率）；改成今日 20 日均 vs 20 日前的 20 日均；回看 20 日需 `setbackbar(21, "D")`。
5. 論壇另有「語法選股」「連續上漲四筆」等條件寫法範例（序列條件可做連續漲停）。

## 三、對照表（小哥規則 → XQ 做得到嗎）
| 小哥規則 | XQ 能做到的對應 | 差異／缺口 |
|---|---|---|
| 帶寬 <5%（窄）、5~10% 普通窄、≥20% 寬 | 帶寬腳本可直接改門檻 | XQ 範例預設 **10%**；公式 (上−下)÷中 與小哥 上÷下−1 略有差異（窄帶時差距小，但門檻要自己對） |
| 開布林：前窄（<5%）→往上打開那一根 | 盤末開布林腳本≈「收盤≥上軌＋放量＋月線上升」 | XQ 版沒有『前一日帶寬<5%』與『主力／關鍵分點大買』；放量 1.68 倍是使用者自訂，非小哥數字 |
| 月線方向、上軌斜率≥3%/日 | 20 日均上升／上軌日變化率可自寫 | 小哥用逐日變化率，不用角度；XQ 論壇提醒斜率要在日線上算 |
| 多頭區間來回（月線向上、拉回月線量縮） | 均線、量縮條件可寫 | 『通道平行』需自己定義 |
| 高檔出貨（月線下彎、乖離年線>40%、主力賣） | 月線下彎、乖離率、主力賣超（近 N 日主力買賣超）可選 | 主力買賣超是 XQ 的口徑，不一定等於小哥看的『主力』 |
| 地板股：黑K、量≥20日均量2倍、乖離到『該股歷史』地板價 | 黑K、量比、乖離率可選 | 『該股自己的乖離 5% 分位』要寫腳本回看歷史；內建條件多是固定門檻 |
| 周轉率 >30%（放空三步驟） | 未查到內建條件頁 | 需確認 XQ 欄位名；我們用 成交股數÷發行股數 |
| 連續兩三天漲停、連續大紅 K | 序列條件可寫（論壇有連續上漲範例） | — |
| 關鍵分點、隔日沖分點、大股東賣 | **未查到分點明細欄位**（只有主力買賣超、大戶買賣力） | XQ 無法複製小哥最核心的分點判斷；我們用富邦分點頁自建 |
| 買超認購權證金額、權證券商分點、自營比 | 未查到 | 同上，我們用富邦權證頁＋T86 近似 |
| 連次連量、竭盡點 | 未查到對應 | 小哥自家軟體欄位；我們儀表板有 |

## 四、結論
XQ 能複製小哥的**價量／技術面**部分（帶寬、開布林、月線、乖離、量比、連續漲停），**複製不了籌碼核心**（分點、隔日沖、關鍵分點、權證買超）。若要在 XQ 放小哥規則，只能放技術面前置篩選，再用我們的 /inventory 補分點與權證端。
