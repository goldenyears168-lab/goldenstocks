# 小哥盤點：前瞻驗證手冊與經驗心得

原則（使用者 2026-10-21）：**先回測更多天之前，多次驗證、累積經驗心得。** 做法＝每天前瞻驗證（訊號日 T 收盤後出名單、T+1 看結果），預先寫好假說與門檻，累積到足夠天數才下結論，再決定要不要做更大的回測。

## 一、機制（全部自動，每晚 22:30 之後）
1. `xiaoge_chip_daily.py --burst`：漲停／爆量股＋前一日 M09／M07 命中股補抓分點頁（保證有「隔天」的資料）。
2. `xiaoge_inventory.py`：M01–M09 當日命中。
3. `xiaoge_m09_followup.py`：T→T+1 實際發生什麼（flagged 隔日沖分點賣了多少、賣壓占量、接手力、跳空／開→收／收→收、盤中氣氛）。盤中資料來自 `xiaoge_m09_intraday.py`（08:25–13:32 記錄試撮、高低、五檔委買賣、漲停跌停）。
4. `xiaoge_validation_journal.py`：預註冊假說 H1–H6 的當日結果與累積 OOS 計分（`validation_tally.json`、`validation_journal.md`）。
5. `xiaoge_ledger.py --live`：訊號帳本（各戰法 T+1／5／20 日超額）。
6. AI 步驟寫 `inventory_<日>_ai.md`，最後一段是當日心得（只能引用以上檔案、不得改假說或門檻）。
8771 `/inventory` 依序顯示 AI 解讀、戰法卡、全部命中、隔日追蹤、假說計分、訊號帳本。

## 二、預註冊假說（形成樣本＝T 日 2026-10-20 前；OOS 從 T=2026-10-21 起）
| # | 內容 | 預期 |
|---|---|---|
| H1 | M09 T+1 跳空 ≥4% 者收→收高於 <4% 者 | 差為正 |
| H2 | T 日漲停且 T+1 跳空 <3% 者，T+1 開→收為負的比例 | >60% |
| H3 | flagged 隔日沖占 T 日買盤 ≥50% 且 T+1 跳空 <3% 者，收→收 | 平均為負 |
| H4 | T 日周轉率 ≥30% 的 M09，T+1 開→收低於其他 M09 | 差為負 |
| H5 | M09 整體 T+1 開→收平均 | < −0.3% |
| H6 | flagged 分點照慣性在 T+1 賣出（≥0.7×T 淨買）的比例 | ≥60% |
| H7 | M09 T+1 跳空 ≥4% 者開→收高於 <4% 者（補入；取代 H1） | 差為正 |
| H8 | M09 的 T+1 開→收 低於『同日同流動性、T 日漲≥5%、不看分點』基準 | 日均差 <0 |

> H1 的「收→收」含跳空本身，跳空大者收→收機械性較高，是 10/21 回放時才發現的設計缺陷；H1 保留但標「機械性，不計證據」，由 H7 取代。H7／H8 是看過回放才補入，回放樣本屬事後，前瞻證據從 10/21 起計。
裁決門檻：OOS ≥10 個訊號日且 n≥60 才標「支持／未支持」；8 個假說同時追蹤，|t|≥2.5 才算強。**不得因單日結果改假說或門檻。**

## 三、目前累積的經驗心得（2026-10-21）
1. **隔日沖逐股看紀錄**，不把分點整體貼標籤（使用者指正）。富邦證券在台郡有買進隔日賣紀錄，不能推到別檔。
2. **周轉率看訊號日（漲停／大漲那天），不是隔天或前一天**（使用者指正）。台郡漲停日只有 9.8%（前一天 55.6%），所以不算高周轉。
3. **流動性篩選會漏掉剛爆量的股票**：排名用 20 日平均成交值，台郡 10/15–16 暴增仍進不去，10/16 的富邦證券買進因此缺資料。已用 `--burst` 補（漲停≥9%／量≥3 倍均量，回補 30 日）。
4. **分點收盤後才有 → T+1 開盤進場**。日線層面的檢定：關鍵分點進場無額外預測力（t<2）；價格型 P04 高檔出貨 5 日反而 +1.06%、P05 地板股開盤進場為負（書中買法是第 2 天殺低時進，不是開盤）。
5. **2026-10-20→10-21 的 M09 觀察**（18 檔，半天快照，描述性）：開盤跳空大者（律勝＋9.3%、德淵＋7.7%、強新＋6.5%）續漲停；跳空小者（聯一光＋1.9%、今國光＋1.8%、台郡＋2.2%）被倒貨，聯一光盤中摸近漲停後崩到近跌停（隔日沖占前 5 名買盤 92%）。例外：GIS-KY 跳空 2.2% 仍漲停。→ 形成 H1–H3。
6. **反彈日會掩蓋空方線索**：10/21 全市場開高 +1.1%，被打到月線下彎的偏空名單反而比大盤強；評估空方線索要看「開盤後」與扣市場，不是收盤漲跌。
7. **測量陷阱**：beta 調整（用等權母體估）平均 beta 0.85，使母體超額非 0，改以等權超額為主；盤中快照是 13:12 的半成品，不是收盤；4 次全市場快照後改用單檔報價記錄器，避免再打富邦。
8. **小哥 2026-10-20 的四句**（委買太多殺尾盤、高周轉＋隔日沖＝弱、隔天漲停最好殺、周轉率 30%+）尚待字幕確認含意；「委買」「隔天漲停」兩句因含意不明，只記錄 13:00 後委買／委賣量，不做規則。
9. **M09 假陽性**：大型股的外資券商（摩根、高盛等）買賣都大，也會有「隔天賣」紀錄，人工判讀；後續考慮收緊為「≥3 次事件且隔日賣比例 ≥50%」，但要等累積後再改，避免事後調參。

## 三之二、歷史回放（更早以前，2026-08-26～10-19，35 個訊號日，M09 363 筆；`xiaoge_m09_replay.py`）
只用當日流動性前 N 名的 PIT 列（排除 `--burst` 依 10/20 結果補的列），habit 只用 T 以前的資料。這批日子早於假說形成日，算歷史偽樣本外（事後補的 H7／H8 不是）。
- **H5**：M09 T+1 開→收平均 −0.41%（日期叢集 t −1.28），56% 為負；方向對，扣約 0.3% 成本後接近零。
- **H2**：昨日漲停且跳空 <3% 者，開→收為負的比例只有 52%（n=126），**未達 60%，不支持**。
- **H3**：隔日沖占買盤 ≥50% 且跳空 <3% 者 −0.67pp（t −1.2，n=102），同向但不顯著。
- **H4**：回放期間 T 日周轉率 ≥30% 的 M09 只有 7 筆，**資料不足**。
- **H6**：照慣性隔天賣出的比例 59.8%（≈60% 門檻）。
- **H7（跳空與開→收）**：跳空 <2% −0.35%、2~4% −0.87%、4~6% −0.59%、≥6% +0.03%（n=274/53/16/20）；**不是單調關係**，只有最大跳空組沒有被殺。10/20 那批『跳空大續強、跳空小被倒貨』在 363 筆裡沒有複製成穩定規則。
- **H8（最重要）**：同日同流動性、T 日漲≥5% 但不看分點的基準（n=1,504），T+1 開→收本來就是 **−0.54%（58% 為負）**；M09 是 −0.41%，日均差 **+0.30pp（t 0.78，35 天）**——**隔日沖慣犯標籤相對『大漲後的一般股票』沒有額外下殺**。這與先前全市場檢定（慣犯隔天更常賣，但價格結果為零）一致。
- 強（≥2 次）−0.54% 對弱（1 次）+0.14%，差 0.7pp，n 分別 296／67，未檢定。
**心得**：大漲隔天開→收平均為負是整個市場的現象，不是隔日沖的專利；要證明小哥的隔日沖線索有增量，必須對基準（H8）而不是對零。

## 三之三、組合技檢定（走動式樣本外，2024-10～2026-07，13,024 個「T 日漲≥5%、流動性足」個股日；`xiaoge_combo_study.py`、`xiaoge_combo_followup.py`）
目的：小哥的因子是組合使用，不是單因子切分。結果變數＝T+1 開→收（扣當日同母體均值）；特徵 23 個（價量＋隔日沖慣犯等分點特徵）；每月走動式、purge 5 日。
- **加法 vs 交互**：樹深度 1（純加法）/2/3/4 的 IC 為 +0.055/+0.063/+0.056/+0.050；最差 20% 做空淨（扣 0.3%）+0.42/+0.54/+0.48/+0.44%／日。**交互最多多 0.1pp，信賴區間重疊 → 沒有證據顯示『組合』比各因子加總更強。**
- **單因子 IC 最高的反而是方向相反**：n_habit +0.063（t 5.3）：慣犯越多，T+1 開→收『越不差』，與『隔日沖→倒貨』假說相反（可能混了大型／機構股較耐震，logp、n_big 同向）。
- **最差預測五分位的樣子**：低價（−0.49σ）、前5大買超的大買家少（−0.44σ）、慣犯少（−0.42σ）、周轉率高（+0.30σ）——即『沒有大買家撐盤的散戶高周轉股』，不是『有隔日沖的股』。
- **CART 組合規則**：深度 3 的規則在後 40% 日期驗證，BH 校正後沒有任何葉子顯著（q≥0.3）。
- **可交易性很邊際**：扣 0.3% 成本 +0.48%／日（t 3.2）；成本 0.45% 降到 +0.33%（t 2.2）；加 +5% 強停再降到 +0.09%（t 0.6）；0.6% 成本為負。5/6 個季度為正（2025Q4 約 0）。不含券差／借券／開盤抓不到空單。
- **脆弱性**：缺值處理方式不同（中位數補 vs 樹原生處理），深度 3 的做空淨從 +0.61% 變 +0.48%，顯示結果對預處理敏感。
**心得**：1) 我們缺小哥的核心主表（買超認購權證排名＋自營比＝權證賣壓），目前的『組合』少了最重要的一個因子，所以『沒有組合優勢』不能推論成『小哥的組合沒用』。2) 結果變數用開→收，與小哥『10 點前出場』不同。3) 三大法人自營商買賣超（TWSE T86 全市場可免費回補）可能是『自營比』的代理，值得補。

### 加入三大法人（官方 T86／櫃買，DB 已有 2024-06 起全市場；`xiaoge_combo_inst.py`）
- 單因子 rank-IC：自營比（自營商買賣超÷成交量）+0.012（t 1.0）、外資 +0.034（t 2.8）、投信 +0.021、三大法人合計 +0.049（t 4.0）；方向都是『買越多隔天越不差』，自營比本身沒有預測力。
- 走動式：加法 ridge 的 IC 從 +0.054 降到 +0.042；樹 +0.056 → +0.053；做空淨（0.3%）+0.36→+0.42 與 +0.61→+0.60，**加入法人沒有改善**。
- **小哥式組合規則（事前寫死）**：自營比≥2% 且有隔日沖慣犯且外資投信未買超：n=145、81 天，T+1 開→收 −0.54%，但扣當日均值後超額 0.00%（t 0.3），**沒有增量**；只加到『自營比≥2%＋慣犯』（n=1,253）反而超額 +0.13%（t 2.5），方向與假說相反。
- 判讀：官方自營商買賣超是『結果』（含避險與自行買賣），不是小哥看的『權證買超金額＋誰在買認購權證』。真正的缺口仍是權證端資料（哪些分點買了多少認購權證、是不是隔日沖），目前尚無來源。
