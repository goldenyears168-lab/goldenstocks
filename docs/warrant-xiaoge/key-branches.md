> 建立日 2026-10-18；來源：小哥影片字幕／說明欄抽取（約 35 支影片，其中 6+5+3 支有字幕全文，其餘僅標題／說明欄）。

## 先講結論：字幕裡的「關鍵分點」是行為描述，不是公式

- 全部字幕中**沒有任何一處**給出可計算的關鍵分點挑選公式，也沒有給出一份指名的關鍵分點清單。[事實：抽取 agent 逐支檢視後的共同結論]
- 具名分點只有零星舉例，且多數是自動轉寫字幕，名稱待核；本庫因此把『泛稱類別』與『具名分點』分開列。
- 本庫是**線索庫，不是訊號**。repo 內已有否證：`關鍵分點前選後驗`（159檔22窗隔日進場全不優於隨機）、`籌碼SOP對隔日收盤判決`（無獨立預測力）。看多看空皆不得拿本庫當進場依據。

## 一、行為特徵清單（小哥口述的關鍵分點樣貌）

1. 低檔大買、高檔大賣：「高檔拼命賣、低檔拼命買」，跟著低買高賣。
2. 長期獲利者、常為地緣／公司派／內部人（可成：台南、高雄分點），**先於主力進場**。
3. 標的要高殖利率（約≥5%）才抱得住；殖利率降到4%以下或關鍵分點出脫＝出場。
4. 搭配布林通道：壓縮(<10%、5%、3%更好)後第一根突破＋主力都在買；大盤盤中大跌時買低檔股。
5. 低檔在賣的不算關鍵分點（否定例：台灣匯立）。
6. 近期關鍵分點買的偏小型、高殖利率股；大型股位置關鍵分點未必想買。
7. 在地板股SOP中只是加分項（第4項），沒有也照搶（聯發科例）。
8. 每天整理關鍵分點買賣給訂閱者；買進理由要列5項且含籌碼。
9. 反例/對照：隔日沖、假主力、停損大戶、散戶分點（國泰敦南）、外資高買低砍——小哥把它們當『別跟』或『反著做』。

## 五、對照 repo 的方法與限制

- `stock_broker_branch_daily`（stocks.db，唯讀；以 2026-10-14/15 的 securities_trader_id/名稱去重得 1017 組 id-名稱）：同一 id 常有兩種名稱寫法（如永豐內湖／永豐金內湖）。
- `stock_branch_daily` 只有每股聚合（buy_top5_net 等），無分點名，不可對照。
- `broker_history.db` 是使用者自己的下單/成交紀錄（broker_orders/fills/realized），不含分點，不可對照。
- 比對規則：名稱完全一致→exact；只有部分字（如 土城永寧→元大永寧）→candidate；沒有→none；泛稱→category。均不硬配。

統計：共 36 筆（具名 branch/broker 21、類別/地緣 15）；repo_match：{'exact': 12, 'none': 5, 'candidate': 5, 'category': 14}。
