# 台虹(8039) 隔日沖慣犯試跑（2026-10-20）

腳本：`scripts/research/branch_flip_habit.py`（唯讀 `stock_broker_branch_daily`）。定義與參數見腳本檔頭：買超前 5 名且淨買 ≥3% 當日買進量為「大買事件」；近 90 日在該股至少 2 次「大買後隔日賣出」＝慣犯。隔日沖旗標有兩種口徑：A＝次日賣出量 ≥70% 淨買；B＝次日淨額（買−賣）≤ −70% 淨買。

|---|---|---|---|---|---|
| 富邦證券 | 3,493 | 7／6 | 是 | 735／4,369 | 是／是 |
| 凱基-城中 | 1,548 | 3／3 | 是 | 182／956 | 否／否（賣出為淨買的 62%，未達 70%） |
| 凱基-台北 | 1,159 | 4／4 | 是 | 6,808／7,799 | 是／是 |
| 統一 | 771 | 4／4 | 是 | 802／911 | 是／否 |
| 統一-城中 | 728 | 0／0 | 否（無歷史） | 108／777 | 是／是 |

前三名都賣、且慣犯判定 4／5；沒有歷史紀錄的統一-城中也賣了。

## 全期檢查（台虹 2026-03～10，187 個大買事件）
- 口徑 A：基準隔日沖率 54.0%；判為慣犯 102 次、命中 59.8%；非慣犯的隔日沖率 47.1%（差 +12.7 個百分點，z≈1.7）。
- 口徑 B：基準 26.7%；慣犯命中 24.6%；非慣犯 27.8%（無差異）。
- 結論：**慣性可以量化，但「慣犯」對隔日賣出的區辨力與口徑有關**：以賣出量定義有小幅提升，以淨額定義沒有。單檔單一時期、事件彼此重疊，不能外推；正式檢定要跨股、分期。
