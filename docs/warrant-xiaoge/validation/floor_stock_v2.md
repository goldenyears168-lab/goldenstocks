# 地板股 SOP v2（依官方投影片重做）· 2026-10-18

**結論先行**：判決由 v1「不支持」改為 **混合**。依官方投影片的操作順序（Day1 近地板＋爆量黑K → Day2 下跌>3% 黑K 殺低進場 → Day3 開高了結，否則最多持 5 日）：勝率宣稱 95–99% **不成立**（毛勝率 74%、淨勝率 68%）；期望值為**小正但未達顯著**（淨均值 +0.67～+1.27%，t 0.5～0.9；對 0050 超額 +0.06～+0.56%，t 0.15～1.16）。比「無地板條件」對照組（超額 −0.39%，t −2.25）好約 0.9 個百分點，所以**地板條件有資訊，但不足以獨立撐起策略**。結果對「Day2 進場價」假設敏感（進場取低收中點 → 超額 +1.0%，t 2.04）。

## 一、官方畫面（`docs/warrant-xiaoge/screenshots/`）給的新資訊 [字幕＋畫面]
- 四要件投影片：①昨黑K爆量（有出量有人撿）②**乖離月線大到地板價**有機會反彈 ③標的股本越大越好、基本面要好 ④有關鍵分點買更佳。
- 六步驟：①資金 10 等份 ②**當天晚上**出現「小於地板或近於地板」且下跌帶量（≥20 日均量 2 倍）者列入自選（建議有權證標的）③第一份 10%，**第 2 天殺低爆量**搶，「買黑K不買紅K」，**下跌>3%** 且出量更好 ④第 3 天開高上漲無力就獲利了結 ⑤若第 3 天再殺低爆量，用第二份（20%）再搶 ⑥5 天內獲利機率高，沒賺還是得跑。
- **「地板價位」是一條價格線（與「天花板價位」對稱）**，案例聯發科 2454（2025-04）：地板價位 1277.06、天花板價位 1563.14；4/8 爆量出現在地板、4/9 持續爆量跌停進場、4/10 漲停。
- **反推（[事實] 一檔吻合到 0.04%）**：地板價位 ＝ MA20 × (1 − k)，天花板價位 ＝ MA20 × (1 + k)，**k ＝ 該股「收盤對 MA20 乖離（C/MA20−1）」全部歷史的 5% 分位之絕對值**。2454 在 2025-04-09：MA20=1420.5、k=10.06%（全歷史自 2004）→ 地板 1277.63、天花板 ≈1563.4，對照畫面 1277.06／1563.14（差 0.04%）。**[推論]** 其他股同口徑（只驗證一檔）；若只用 2012 起的歷史，k=8.3%、地板 1302（不吻合）。

## 二、預註冊定義（跑之前寫定）
| 項 | 定義 |
|---|---|
| 地板價位 | MA20 × (1 − k)，k＝−(截至 T−1 的全部歷史 C/MA20−1 之 5% 分位)，至少 250 筆；歷史自 2004-03 |
| Day1 | 收盤 ≤ 地板×1.02（「小於或近於」；strict＝≤地板）∧ 量 ≥ 2×前 20 日均量 ∧ 黑K（收<前收；變體 收<開）∧ 20 日均成交值 ≥1 億（「股本大」代理）∧ 收盤 ≥10 元；排除疑似拆分／減資窗 |
| Day2（進場日） | 收盤較前收下跌 ≤ −3% ∧ 收<開（買黑不買紅）∧ 非一字跌停；**進場價＝Day2 收盤**（日線代理；變體：低點與收盤中點） |
| 出場 | S（SOP）：Day3 開盤 > Day2 收盤（開高、非一字漲停）→ 開盤賣；否則進場後第 5 個交易日收盤。F：一律進場後第 5 日收盤 |
| 成本／基準 | 來回 0.44%；減 0050 同窗；日期叢集 t；IS＜2021／OOS≥2021；同股 6 日內不重複 |
| 對照 | 無地板條件（Day1 只要黑K＋爆量＋流動性，其餘相同） |

## 四、解讀（[推論]，假設已標）
1. **宣稱 95–99% 不成立**：毛勝率 74%（S）／58%（F），淨勝率 68%／56%。**勝率高、賺小賠大**（S 的淨中位數 +0.6%，均值 +0.7%）。
2. **地板條件有邊際資訊**：同樣的 Day2 殺低進場，有地板條件 vs 無地板條件，超額差約 0.9 個百分點（SOP +0.06% vs 對照 −0.26%；F +0.56% vs −0.39%）。**假設**：對照組與 SOP 的 Day2 條件相同，差異只來自 Day1 的地板條件。
3. **OOS（2021 後）較好、IS 較差**：不是穩定性證據（OOS 含 2025-04 恐慌日）。
4. **進場價敏感**：小哥實際在「殺低爆量」盤中買，可能優於收盤價；中點假設超額 +1.0%（t 2.04）。**[不足]**：需盤中資料（本機 kbar_5m 覆蓋有限）才能界定。

## 五、不能下的結論
- Day3 再殺低加碼（第二份 20%）、「開高上漲無力」的盤中判斷、基本面與股本篩選（用成交值代理）、關鍵分點加分、權證／股期工具**皆未測**。
- 地板價位公式只在一檔（2454）對到 0.04%；其他股的 k 口徑未驗證。
- 日線代理，無盤中；價格未還原除權息；多重變體未校正；t 以進場日叢集。
