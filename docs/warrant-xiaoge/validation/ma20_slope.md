# 月線斜率（R19）驗證：>1% 強、2.5–3.5% 過陡、回檔近月線買點

日期 2026-10-18 · 腳本 `scripts/research/xiaoge_validate_ma20_slope.py` · 結果 CSV `scripts/research/_xiaoge_ma20_slope_out.csv`

## 結論先行（判決：不支持）

- **[事實]「月線斜率 >1% 很強」不成立**：S>1% 組 T+1 開盤進場、扣 0.44% 成本、減 0050 後，1/5/10 日平均超額 −0.85%／−0.77%／−1.01%，與全樣本基準（−0.69／−0.85／−1.10）幾乎一樣；超額**中位數**反而更差（−1.12／−1.89／−2.69 vs 基準 −0.76／−1.18／−1.67）。沒有任何持有天數贏過基準。
- **[事實]「回檔靠近月線＋斜率>1% 為買點」不成立**：n=2,276（1,051 個交易日），超額均值 −0.94／−1.32／−1.98%，中位 −0.98／−2.59／−3.84%，**比基準更差**（NW t = −7.7／−3.4／−2.8）；OOS（2025 起）更差（−1.26／−2.07／−2.57%）。同樣的回檔條件配 S 0–1% 為 −0.73／−0.80／−1.24%，亦即斜率越陡，回檔後越差，與小哥方向相反。
- **[事實]「2.5–3.5% 過陡」只有部分得到支持**：該組 5/10 日**平均**超額 −0.22／−0.63%（t≈0.7／0.3，比基準好，無法說更差），但**中位數**較差（−1.72／−3.13 vs 基準 −1.18／−1.67）、1 日平均 −0.82%。「過陡不好」在中位數上成立、在平均上不成立，即報酬右偏、典型個股較差。n=7,253 且有重大選樣偏誤（見限制），不能下定論。
- **[推論]**（假設：開盤進場、一般流動性股票池）月線斜率本身不是正向 alpha 篩選；斜率>1% 的股票平均已大幅偏離月線，T+1 追價吃到的是回吐。這與本 repo 他處「追價/高位無獨立預測力」的結論一致。
- 注意：基準本身 T+1 開盤→收盤 1 日超額 −0.69%（含成本 0.44%），即全市場開盤買進當日收盤賣出對 0050 就是輸；因此判斷一律看「相對基準」。

## 預註冊定義（跑之前寫定）

- 資料：`stock_daily_bars`（唯讀），只用 `twse_mi_index`/`tpex_daily` 原始價（`finmind` 已退役、`adj_close` 覆蓋不全；**未還原除權息**），期間 2018-07-02～2026-10-15（含 MA 暖機）。宇宙：4 位數代號 1xxx–9xxx、已有 ≥300 日資料、近 20 日均成交值（close×volume）≥ 3e7 TWD。
- S = MA20_T / MA20_{T−1} − 1（MA20 為收盤 20 日均，T 為訊號日，只用 date ≤ T）。分層 [−∞,0)、[0,1%)、[1%,2.5%)、[2.5%,3.5%)、[3.5%,∞)；並合併 S≥1%。
- 「回檔靠近月線」：T 收盤 / MA20 − 1 ∈ [−1%, +3%]，且 T 收盤 ≤ 近 5 日最高收盤 × 0.97。「主力還在買」**無法程式化（小哥未給算法，且本 repo 籌碼面已多次檢定無獨立預測力），未納入**。
- 進場 T+1 開盤；出場 T+h 收盤（h = 1, 5, 10；h=1 即 T+1 開→收）。淨報酬 = 毛報酬 − 0.44%。超額 = 淨報酬 − 0050 同窗開→收毛報酬（0050 2025-06 分割窗口設 NaN）。
- 排除：近 21 日有 |日報酬|>11.5%（疑分割/除權/異常）、T+1 開盤相對 T 收盤 ≥ +9.5%（開盤漲停買不到）、單筆淨報酬 |r|>60%。
- IS = T < 2025-01-01，OOS = T ≥ 2025-01-01。統計：樣本數 n、中位淨報酬、勝率（淨報酬>0）、平均/中位超額、t = 每日截面平均超額序列的 Newey–West t（lag=h），即以日期為叢集。
- 基準 = 同一宇宙全部 stock-days（"S all"）。

## 限制與誠實揭露

1. **[事實] 對陡斜率組的選樣偏誤**：我排除了「近 21 日內出現 |日報酬|>11.5%」的股票（為擋分割/除權假訊號），這同時剔除了許多真正的急漲股，所以 S>2.5% 兩組（n 僅 7,253／2,018，已被大幅削減）**不代表小哥所說的飆股**。2.5–3.5%/>3.5% 的結論效力弱。
2. **[事實] 未還原除權息**：除息日價格跳降會使 MA 斜率與報酬都有輕微偏誤；已用 11.5% 閾值擋大額事件，小額除息未處理。
3. **[事實] 「主力還在買」未檢定**（無可重算定義），「剛開布林、月線還很平」之買點條件（說明欄 2025）屬另一個檢定（需布林帶寬定義），不在此報告範圍。
4. **[事實] 標的為近 20 日成交值 ≥ 3e7 的全上市櫃股**，不是小哥的當沖神器選股池；基準本身相對 0050 為負，所以絕對報酬應讀作「與基準的相對差」。
5. **[推論]** 1/5/10 日窗互相重疊；已用 NW 校正，但 t 值仍可能偏樂觀；結論不依賴小的 t 差異。
6. 出場用收盤價，未模擬小哥的停損/移動停利；他的「回檔買點」若搭配分批與停損可能與固定持有期結果不同——**此為猜測，未檢定**。
