# R67 處置浪子回頭驗證

## 結論（先行）
- **「10 檔 9 檔反彈」不支持**：[事實] 148 個事件，進場後 5/10 日毛報酬為正的比例僅 **61% / 65%**（扣成本後同為 61% / 65%，因均值遠大於成本；對照基準：0050 同期上漲比例 69% / 61%）。距 90% 差 25 個百分點以上。
- **但有溫和的正向偏移**：[事實] 淨超額（扣 0.44%、減 0050）均值 h5 **+3.29%**（t 2.1）、h10 **+4.03%**（t 2.1），中位 +3.3% / +3.1%；OOS（舊制後半）同號且 h5 t 2.6。對照組（同價格條件、非處置期間）淨超額僅 +0.84% / +0.53%，處置事件高出 +2.4 / +3.5pp。
- **判決：混合**。方向（處置窗內深跌回月線後有正超額）有證據，勝率宣稱不成立；[推論，假設＝與已知「處置持有窗本身 ≈ +3.5%」同源，見 memory disposal-dip-chip-verdict] 這個正超額多半是整個處置窗的漂移，而非「回測月線」這個條件的增量（本檔未做「窗內其他日」的同窗對照，故此項**未被本檔檢定**）。
- **主力籌碼條件（第二步）不足**：籌碼分點表全市場只到 2026-07-16 且 2022–2025 覆蓋稀疏，本事件集無法形成可用子樣本；補全歷史分點資料才能答。
- **新制（2026-08-10 起 5 日）n=4，不足**（h10 t 3.9 無意義，n 太小）。待 ≥100 事件再判。

## 預註冊定義（跑之前寫定）
- 母體：`disposal_windows.csv` 第一次／第二次處置窗，start ≥ 2020-02-01（共 1051 窗），個股日 K 取 `stock_daily_bars`（twse/tpex 優先）。
- 高位修正：訊號日 T 收盤相對近 20 交易日（含 T）最高收盤 ≤ −20%（dd）。
- 回測月線：T 最低價 ≤ MA20×1.02 且 T 收盤 ≥ MA20×0.95（可跌破一點，呼應 2026-06-14「跌破月線不一定出場」）。
- 事件：窗內（start..end）**第一次**同時成立之日 T，每窗最多一筆。
- 進場 T+1 開盤；出場 T+5 / T+10 收盤（持有 5/10 個交易日含進場日）；扣成本 0.44%；超額＝減 0050 同期（T+1 開→T+h 收）。
- 「反彈」＝進場開→出場收毛報酬 > 0。t 以訊號日為叢集。IS/OOS＝舊制訊號日中位（2021-07-16）前後；新制（≥2026-08-10）另列。
- 對照組：同 dd∧touch 條件、不在任何處置窗內，每檔 10 日去叢集。
- 敏感度：僅 dd ≤ −20%（不要月線）。
- 主力籌碼條件：預定義為 conc5/conc10>0（見 warrant_xiaoge_disposal.py），但資料不足故不報。
- 腳本：`scripts/research/xiaoge_validate_disposal_prodigal.py`（DB 唯讀）。

## 樣本
- 事件 n=148（舊制 144、新制 4）；時間分布集中在 2020–2021 與 2026（[事實] 事件期間 2020-02-06 ~ 2026-08-13，2022–2025 僅約 10 筆，反映當年價格面板覆蓋不足，非處置少）。平均於窗第 6.5 天觸發；中位 dd −25.1%。

## 解讀與限制
- [事實] 勝率 61–66%，非 90%。[推論] 小哥的 9/10 可能是挑選案例（倖存者／事後選圖）或使用更嚴的未公開濾網（主力籌碼條件、基本面），本檔無法區分。
- [事實] 均值為正但中位數遠小於均值的程度有限，分布右偏；單一事件波動大（處置股），5 日內 t≈2 屬弱證據，IS h5 不顯著（t 0.7）。
- [推論] 與對照差 +2.4～3.5pp，但對照組為「全市場同條件非處置」，兩組波動度與市況時點不同，差值不是乾淨的處置效應。
- 多重比較：本檔主指標 h5/h10 兩個、子集若干，未做校正；請勿視為確證。
- 未做：窗內非訊號日同窗對照、融資券／基本面、新制樣本、持有至出關日版本（見 `disposal-dip-chip-verdict`：持有窗本身 ≈ +3.5%）。
- 補什麼才能答：①2022–2025 價格面板補齊（目前事件稀疏）；②全期分點資料以檢定「主力未跑」；③新制累積 ≥100 事件。
