## 5.0　本部在小哥總管線中的位置

小哥的整條管線是：

大盤環境 → 清單（每日／每週）→ 形態確認 → 籌碼確認 → 價值／意圖確認 → 工具選擇 → 扳機 → 出場 → 風控

當沖是這條管線裡「工具選擇」選了現股當沖（或股票期貨當沖）之後，最貼近盤面的那一段：

| 管線階段 | 在當沖裡對應的動作 | 本部章節 |
|---|---|---|
| 大盤環境 | 今天我覺得是黑 K 還是紅 K（決定先賣再買，或先買再賣） | 5.9 |
| 清單 | 量大、波動大、前一天有大漲的熱門題材股；盤後先看籌碼 | 5.3、5.13 |
| 形態確認 | 月線抖不抖、布林通道方向，判斷強勢股能強幾天 | 5.3 |
| 籌碼確認 | 盤前看試撮、正逆價差比；盤後看分點，誰害我賠錢、誰在停損 | 5.4、5.13 |
| 價值／意圖確認 | 這個漲停或這個大單，是真的要拉，還是隔日沖在出貨 | 5.4、5.7 |
| 工具選擇 | 現股當沖／資券當沖；日內波或 Tick 流 | 5.2、5.8 |
| 扳機 | 連次連量達 ±10 亮燈、轉色，漲到買盤竭盡去空、跌到賣盤竭盡去買 | 5.5～5.7、5.10 |
| 出場 | 反向竭盡點回補；13:15 前停損平倉 | 5.11 |

整部書的核心，是我在 V10 結尾說的一句話：

「當你會抓轉折，你才能來做當沖；你不是沒事看到就買、想到就賣，那種大概率都是賠錢。」〔V10 22:30〕

## 5.1　為什麼做當沖：優點、缺點與心態

### 這是什麼

當沖就是同一天買進、同一天賣出（先買再賣，或先賣再買），收盤不留部位。

### 為什麼這樣做

我把當沖的優點歸納成四個〔V10 4:40–6:15〕：

1. **沒有隔夜風險。**「你不用怕今天晚上川普又對伊朗幹了什麼事。」
2. **資金效率高。** 當沖會來回做很多，有時候一天衝就是衝幾億到十幾億。我們量最大的時候是做結算那一天，我們其實都是找事件來沖。結算日很好做：我這邊用現貨沖、那邊用期貨避險，可以做套利，有時候會把戶頭的額度沖到沒了。〔V10 5:45–6:11〕
3. **證交稅減半。**
4. **快速累積經驗。**

缺點也有四個〔V10 6:15–7:30〕：

1. **交易成本侵蝕獲利。** 手續費和交易稅非常可觀，我一個月的交易稅都是上百萬，一年上千萬。
2. **沒辦法融券，只能付昂貴的借券費。**
3. **壓力與情緒負擔大。** 要盯盤，我看當沖的人衝一衝都會變胖：不順利的時候身體覺得遇到危險，就幫你囤積能量。
4. **違約交割風險，這是我覺得最嚴重的。**

關於違約交割，我的觀察是：沖不掉，都是不甘心停損才會沖不掉。放空遇到漲停、做多遇到跌停，我們看過很多違約交割的，會去看他的分點跟點位，大部分都捨不得停損。一次違約交割，他一輩子大概就掛了，所以各位一定不要去觸犯違約交割的條款。〔V10 4:56–5:21〕

還有一句我常講的話：「憑感覺做當沖，用運氣賺錢，用實力輸回去，你怎麼來的就會怎麼吐回去。我沒看過贏錢的。」〔V10 6:16–6:30〕

最常見的死法〔V10 20:08–20:36〕：原本做當沖，套牢不賣，賠錢變存股；存股完了又遇到處置，被關又往下殺。這是最慘的：他不去懂股票的節奏，一直靠情緒下單，也不管處置、不管事件。

### 怎麼做

- 把當沖當成「用數據判斷轉折」的工作，不是用感覺。
- 我自己的做法是「停損 % 數設大一點，但張數不要太大」（見 5.11）。
- 做當沖前，先把「盤前、盤中、盤後」三段功課排好（見 5.4、5.5、5.13）。

### 檢查表

- [ ] 我能說出今天每一筆單的進場理由是數據（連次連量、竭盡、籌碼），而不是感覺嗎？
- [ ] 我有沖不掉的備案（資券戶都開、知道停損點）嗎？
- [ ] 我有被套就改成「存股」的習慣嗎？（有的話，先改掉）
- [ ] 我知道手續費與證交稅會吃掉多少利潤嗎？

## 5.2　資格、成本與帳戶

### 這是什麼

進場前要先把當沖的資格和成本弄清楚。

### 怎麼做〔V10 2:50–4:35〕

**現股當沖資格：** 開戶要滿三個月、今年成交 10 筆以上、簽署風險預告書。

**資券當沖資格：** 門檻比較高，今年成交金額要達 25 萬，還要開信用交易帳戶。

**我強烈建議兩個都要開起來。** 理由：做現股當沖時可能突然沒沖掉，例如先賣之後被鎖漲停，因為沒開資券戶就找不到券，勢必要去借券；借券費、手續費再加上隔天的跳空，有時候會賠得很大。有資券戶，至少可以改成券來沖。

**成本：**

| 項目 | 數字 |
|---|---|
| 手續費 | 千分之 1.425 |
| 手續費議價 | 量大可以談；做到一個月上億以上，有機會談到二三折 |
| 當沖證交稅 | 千分之 1.5（一般證交稅是千分之 3，現股當沖有打折） |

事實上我沒有那麼大，台面上可能有人這樣說，但實際上比我大的人很多。〔V10 3:57–4:04〕

**股票期貨當沖與現股放空的限制：** 現股放空會遇到融券、被標借、有券差；股票期貨沒有這個問題。這些風險我都遇過，是用金錢跟時間換來的經驗。〔V11 47:17–48:20〕看盤口時，我是直接看現股的五檔，因為會掛假單的都是在現股掛，不會在股期掛。〔V11 29:21–29:48〕

### 檢查表

- [ ] 現股當沖資格（滿三個月、10 筆、風險預告書）已完成？
- [ ] 資券當沖資格（25 萬成交金額、信用帳戶）已完成？
- [ ] 手續費有沒有依成交量去議價？
- [ ] 我知道放空會碰到標借與券差嗎？

## 5.3　標的與題材：量大、波動大、看強勢能強幾天

### 這是什麼

當沖的標的挑選，是我整條管線的「清單」階段。〔V10 0:54–2:45〕

### 為什麼這樣做

我挑當沖標的有兩個基本條件：成交量要大（流動性要好），波動幅度要大。我的說法是：「波動大就好做，我還怕它沒波動。」波動大的股票，通常都是前一天有大漲的股票。（影片標題：小哥挑選當沖標的 2 個基本條件〔說明欄 2022-12-21〕）

### 怎麼做

**第一，成交量要大（流動性要好）。** 日均量 3,000 張以上，我覺得很基本；3 萬、5 萬、10 萬都很好。例如最近我蠻常沖 00981A，量非常大。

**第二，波動幅度要大。** 00981A 的波動幅度還算沒有很大，但只要大行情，由於量體太大，還蠻好做。波動大的股票，通常都是前一天有大漲的股票，可能就是漲停。

- 前天漲停是**沒有量的漲停**：大概率今天還蠻強。
- 前一天漲停是**爆大量的漲停，或爆大量的長紅**：隔天波動會很大，因為會有很多隔日沖要出貨；隔日沖出貨前，又會誘使人家進去買，讓你覺得「哇，這張股票量滾量好像要拉了」，而事實上他們要出貨。

**第三，熱門題材。** 量要大又要波動大，一定是當下的熱門題材。例如短空的股票，可能就是昨天的強勢股。

**強勢股能強幾天，看月線抖不抖：**

- 月線很抖往上，股價又沿著布林上通道走：這種很強，不知道會強幾天。
- 布林通道走平，或往下，月線往下，這時候的大長紅漲停，通常只強一兩天。〔V10 2:19–2:42〕

**事件面（V10 16:55–18:00，細節見處置股那一部）：** 我們的統計是，大部分被關的第一天平均來講比較弱，所以去做這個策略，平均來講大概會輸錢。五分鐘盤出關的第一天通常比較弱：五分鐘大家都還可以買（像聯發科五分鐘其實也還好，它只是規定你不能買超過 29 張，一般人買一兩張就很多了），很多人想說出關那天會比較強，所以大家都選出關那天賣，當天開高走低的機率比較大；二十分鐘盤出關，據我們統計上漲比較多，因為二十分鐘盤一般人都不能買，必須入金才能買。

**我不會做的狀況：** 有的股票紅紅紅，沿五日線紅上去，我不會再做多，因為你怎麼知道它這次還會紅；它通常會遇到有一天長黑，但你不知道是哪一天；而且這種有的已經快要被關了，你一進場就套牢不賣。〔V10 19:45–20:20〕

### 檢查表

- [ ] 日均量 ≥ 3,000 張？
- [ ] 前一天有大漲（波動大）？
- [ ] 前一天漲停是「沒有量」還是「爆大量」？（爆大量＝隔日沖要出貨，波動大）
- [ ] 月線抖不抖？布林通道方向？（決定這檔強一兩天還是更久）
- [ ] 是不是當下的熱門題材？
- [ ] 有沒有碰到處置、被關、出關這類事件？

## 5.4　盤前：試撮與正逆價差比

### 這是什麼

開盤前的試撮、委託與期現貨價差，我的總則是：

「主力要騙你：他把股票賣掉，就是會讓你想要去買；他假如要去買股票，就會讓你想賣股票。其實你盤中可以跟你的情緒為敵——你想買的時候，可能是想賣的時候。」〔V10 9:42–9:58〕

### 為什麼這樣做

盤前這些短線主力「十個九個騙人」，常常最後一秒抽單。〔V10 7:37–7:47〕我的說法是，短線客都是假拉抬真出貨。〔V12 7:25–7:30〕他們不只盤前撮單，五分鐘試撮額也在玩，最後兩秒才抽單：最後兩秒前撮 360，一抽單變 340。試撮每 5 秒撮合一次，他可以在最後 5 秒把單子刪掉，股票從漲停變跌停；而且他們是用程式掛單。〔V10 7:53–8:05；V12 7:30–8:00〕曾有一位後來成為大戶的主力問我，券商該刪的單沒刪掉可不可以求償，我跟他說，掛這種單子本來就有風險，只能吃下來。〔V12 8:09–8:44〕

### 怎麼做

1. **盤前掛價：** 掛賣就掛高一點，掛買就掛低一點，就有機會掃到；盤前不用那麼害怕買不到。例外是這檔股票真的很強，例如期貨開 7、8%，現貨試撮的委買張數越來越多。〔V10 8:10–8:34〕
2. **試撮委買張數：** 越來越多，有可能是真的；在 59 分之後開始急遽減少，很有可能是假的。〔V10 8:42–8:57〕
3. **試撮漲停怎麼辦：** 看期貨有沒有漲停、有沒有大漲。期貨連大漲都沒有，大概率這個試撮漲停是隔日沖去弄的：隔日沖習慣「上去就下來」，先給你撮漲停，讓一些人去追。前幾天還有一個人因為試撮漲停老是騙人家去買而被抓。〔V10 8:57–9:24〕
4. **試撮漲停、開盤沒漲停：** 通常今天都會有潛在賣壓；假如有隔日沖，就很肯定一開盤就被倒貨。〔V10 9:26–9:35〕
5. **試撮跌停、開盤沒有跌停：** 有可能這個試撮跌停的人是故意要吃貨。〔V10 9:36–9:41〕
6. **正逆價差比（期貨對現貨）：** 盤前正價差比大（期貨比較貴），是主力押股票、買期貨，通常比較偏多（通常，沒有一定）；逆價差比大，是主力拉股票、同時空期貨，通常比較偏空，他主要就是要去建部位。〔V10 10:08–10:32〕

這些我盤中都會從正價差比、逆價差比看得到。〔V10 8:05–8:10〕

### 檢查表

- [ ] 試撮漲停時，期貨有跟著大漲或漲停嗎？沒有的話，當成隔日沖設局。
- [ ] 試撮委買張數是越來越多，還是 59 分後急減？
- [ ] 試撮漲停但開盤沒漲停：先預期有潛在賣壓。
- [ ] 試撮跌停但開盤沒跌停：留意有人故意吃貨。
- [ ] 正價差比、逆價差比偏向哪一邊？
- [ ] 我現在想買（或想賣）的衝動，會不會正好是主力要我做的事？

## 5.6　連次與連量：官方欄位說明

### 這是什麼

連次與連量是當沖神器裡最重要的兩個欄位。官方欄位說明（影片說明欄原文）如下。

**【盤中當沖神器】欄位說明（原文）**〔說明欄 2025-07-09〕

- 連次：每 5 秒，內盤大於外盤為 −1 次，每 5 秒外盤大於內盤為 1 次。
- 連量：每 5 秒內盤成交張數（綠字），每 5 秒外盤成交張數（紅字）。

**連次連量應用方法（原文）**

- 連次達 −10 次（綠）時會有音效，代表個股急殺出量，伴隨大量連次（負數）、連量（綠色）；此時若突然轉變為紅色量時，代表短線上有機會是賣盤竭盡點，可能向上反彈。
- 反之，連次達 10 次（紅）時會有音效，代表短線客大量買進，伴隨大量連次（正數）、連量（紅色）；此時若突然轉變為綠色量時，代表短線上有機會是買盤竭盡點，可能轉折向下。

### 為什麼這樣做

我常用「多軍與空軍廝殺」來想：每 5 秒就有一個結果。連次量假如是紅燈，就是多方獲勝一次；一次、兩次、三次、四次、五次，你知道這個股票越漲越高，多方不可能一直都勝利，總會到一個地方，它的買氣衰竭，紅色的連次量就會變成綠色，那個點就容易是轉折點。〔V10 21:36–21:58；V14 12:01–12:14〕

我在 V14 是這樣講的：極短線我們會利用當沖神器的連次量，因為極短線是在抓轉折或抓發動。連次的「1 次」是 5 秒一次；這 5 秒內外盤成交量跟內盤成交量看哪一個多，外盤獲勝，就連一次紅色；連到十幾次，代表這個買盤已經連勝十幾次了。第一次的最大量、第一次的很大量，那個是**發動量**，例如這 5 秒內第一次 2,000 張的多方量，就是**攻擊量**。〔V14 11:18–12:26〕

### 怎麼做

1. **先看連次：** 外盤連續獲勝，連次為正、紅色；內盤連續獲勝，連次為負、綠色；達到 ±10 就亮燈、有音效。
2. **再看連量：** 連量用紅（外盤）、綠（內盤）區分方向，與連次同時亮燈才是我要的訊號。V10 的技嘉範例：「十次、203，兩個都亮燈」，連次 10、連量 203。〔V10 20:58–21:09〕
3. **多次爆量再搭配急拉，容易出現買盤竭盡**（官方教學語）。官方畫面上的範例讀數格式是「連次／連量」，例如 `2/5`、`20/650`。〔官方畫面〕
4. **轉色是扳機：** 連次達 ±10 後，連量突然變成另一種顏色，才是轉折。
5. **連次量要兩個都亮燈，而且要比這個數字更高；遇到急拉，又有隔日沖，通常容易轉折往下。** 如果是連次量綠色的急殺，容易反彈。〔V10 20:56–21:15〕

> 編者註：連量的欄位說明請以上面說明欄原文為準；我在影片中另外提供的是上述技嘉 10／203、鼎元「連次量去做」的實戰示範，沒有另外給出連量的亮燈門檻或「爆量」的數值，這些細節我沒有在影片中說明。

- [ ] 連量也有亮燈（同方向）嗎？

## 5.7　買盤竭盡與賣盤竭盡：進出場的點

### 這是什麼

我的當沖進出場點，就是「竭盡點」：

「漲到買盤竭盡的時候去空，跌到賣盤竭盡的時候去買。」〔V10 14:01–14:08〕

短片標題也是這句：「漲到買盤竭盡去空；跌到賣盤竭盡去買」。〔官方畫面〕

口訣：**空在爆量漲不動，買在爆量跌不動。**

### 為什麼這樣做

散戶是用情緒下單：看到單子一直攻一直攻，大戶一直在買，他就想進去，那個點我們用軟體看到的是連次量爆量、急拉，這時候容易轉折；所以我是用數據判斷它快要轉折，散戶用情緒買股票。〔V10 18:05–18:37〕反過來，一檔股票殺下來，散戶看到一直賣很恐慌，擊殺出大量，看到出量了又更害怕又去賣，這點常常都是轉折點。〔V10 18:56–19:08〕

所以我常常在今天做的股票大賺錢之後去看分點，國泰敦南又大賠，因為又是他買的：他都買在情緒的高點，砍在恐慌的低點。〔V10 18:40–18:55〕

### 怎麼做

**空在爆量漲不動（買盤竭盡）：**

1. 股票一路急拉，連次達 +10（紅）以上，連量紅色爆量；
2. 你發現它一直出量、一直漲不上去，差不多了、快跌了；
3. 連量突然轉為綠色：買盤竭盡點，準備空。〔V10 21:36–22:20〕

**買在爆量跌不動（賣盤竭盡）：**

1. 股票急殺，連次達 −10（綠）以上，連量綠色爆量；
2. 它一直殺、你看那量一直出來、一直下不去了；
3. 連量突然轉為紅色：賣盤竭盡點，準備做多，它也要彈了。〔V10 22:20–22:30〕

**在日內波裡的使用：** 殺下去有個轉彎的地方我都會買，拉上來快要轉彎的地方我又去空。（見 5.9 的範例對帳單）

**「長不上去」的訊號：** 股價拉高後的「長不上去」訊號，搭配獨特的「買盤竭盡」判斷法，可以抓住股票的空方轉折點。市場偶有「嘎漲停」的停損情況，但學會判斷點位，能大大提升整體勝率。〔說明欄 2025-08-04（精華出處 2025-07-15 直播）〕

## 5.8　日內波與 Tick 流

兩種做法耗費的心力與持倉時間完全不同。我的選擇是：「通常我都會選擇日內波比較好做；除非我當天很閒我在做 Tick 流，或者是我量很大，我就每個 tick 都掛單然後來回刷，這個要本金夠大。」尤其是一兩百塊的，來回刷還不錯。〔V10 10:40–10:59〕

## 5.9　方向與節奏：順大勢、逆小勢

### 這是什麼

這是我盤中的方向原則，分成「大」與「小」兩層：〔V10 12:36–13:49〕

- **順大勢：** 今天我覺得它是黑 K，我就先賣再買；覺得是紅 K，我就先買再賣。
- **逆小勢：** 盤中是一個波動的過程，我在轉彎的地方動作：殺下去有個轉彎的地方我都會買，拉上來快要轉彎的地方我又去空。

官方畫面「多空雙向操作」也是這個意思：做多（期待紅 K）＝買低賣高、預期開低走高、先買進再賣出，最大風險是價格下跌；做空（期待黑 K）＝賣高買低（回補）、預期開高走低、先賣出再回補，最大風險是價格上漲回補虧損。〔官方畫面 V10〕

### 為什麼這樣做

我的觀察是，波動大反而好做：「波動大就好做，我還怕它沒波動，其實有波動都是好事。」太大的時候，用「順大勢逆小勢」的做法來處理。〔V10 12:21–12:36〕

在方向上，我覺得**短空比較容易賺錢**：台股的上漲，大部分取決於跳空，它是給留倉的人一個紅利；我們做過大數據統計，做當沖大部分「先買再賣」的大部分賠錢，「先賣再買」的大部分賺錢。所以為什麼大家做當沖都賠錢，因為大部分都做錯。事實上，你要留波段多單（例如台指期、台積電）去賺過夜的紅利；空單則是當天做短空。因為台股是一個淺跌市場，會有很多隔日沖，昨天買了今天會倒貨，可以運用這些隔日沖倒貨的籌碼狀況來做當沖。〔V10 11:12–12:08〕

### 怎麼做

1. **盤前定今天的大方向：** 黑 K（先賣再買）或紅 K（先買再賣）。
2. **盤中在轉折處動作：** 用連次連量找竭盡點（5.6、5.7）。
3. **符合預想時，來回刷：** 只要符合我的想法，我就會來回刷。〔V10 13:46–13:51〕
4. **留倉與當沖分工：** 波段多單過夜；空單當天做。

### 範例：我昨天的對帳單〔V10 13:02–13:46〕

我打定主意先賣再買，每次有大概轉折的地方就動作：殺下去轉彎的地方買，拉上來快要轉彎的地方空。你可以看到中間在 11 點多的時候買 288，彈上去之後，291、295.5、297 我又再空回去，跌下來再買回去。單子密密麻麻的，事實上我們是順大勢——我覺得它今天應該是黑 K，它也真的是黑 K。

## 5.10　緩搓高點空

### 這是什麼

這是我的極短線手法之一，時間有時候只有 1、2 秒。〔V14 12:36–13:09〕

### 為什麼這樣做

有些股票在多方攻擊的時候，短時間內漲幅超過 3.5%（大概 2 分鐘內），這時候會進入一個「緩搓」；緩搓完，通常會在一個高點做結束。

### 怎麼做

1. 看到 2 分鐘內漲幅超過 3.5%，進入緩搓。
2. 緩搓結束的高點，直接空它。
3. 空完之後它會瞬間下殺，瞬間下殺的那一刻，直接又補掉。

所以這個時間有時候才 1、2 秒而已，反應要很快、手也要很快。〔V14 12:56–13:06〕

## 5.11　停損與部位：竭盡點停損、小賠是好朋友、13:15

### 這是什麼

我的當沖停損準則是：**當沖不要凹單。**

### 為什麼這樣做

平常做當沖會遇到四種狀況：大賺、大賠、小賺、小賠。大賺當然是最好，小賺也不錯，「**小賠是你最好的朋友**，有機會小賠你就小賠」。〔V10 14:11–14:30〕

官方畫面「當沖損益」2×2 說明了這四格：〔官方畫面 V10〕

| | 獲利 | 虧損 |
|---|---|---|
| 大行情 | **大賺**：練就耐心，掌握大行情信心 | **大賠**：絕對禁止，凹單不停損的致命結果 |
| 小波動 | **小賺**：日常交易的基礎累積 | **小賠**：嚴格停損下的正常交易成本 |

底註：拒絕總是陷入「小賺小賠」的泥淖；用紀律切斷大賠，用耐心等待大賺。

### 怎麼做

**1. 用竭盡點當停損點。** 「我大部分的抓停損，我是抓買賣盤的竭盡點。」〔V10 15:10–15:20〕

範例：假設我放空，空在 90 塊，被軋到 93，然後跌下來變 92。93 已經算有點大賠了，跌到 92 變有點小賠了，這時候我會選擇在這個**賣盤竭盡**的點回補。因為剛剛一個買盤竭盡的時候我當然不想在那邊停損；但是下來有個賣盤竭盡，即便它沒到我的成本，我也會停損，這個停損的點就是個小賠的點。〔V10 14:31–15:10〕

**2. 最大停損約 5%。** 當沖的最大停損，大概 5% 我就會很想停損了；但你也不能設太小，設太小一直在停損，也賺不到錢。〔V10 15:19–15:31〕

**3. 停損 % 數設大一點，張數不要太大。** 當你張數大的時候，都是有賺錢的時候；那張數就可以來回算；假如沒賺錢，我的張數就不會大。（賺錢才放大張數）〔V10 15:35–15:47〕

**4. 13:15 前停損平倉，並設好觸價單**（日內波）。〔官方畫面 V10〕

**5. 絕對金額停損：** 我另有一支短片叫〈小哥密技！絕對金額設停損〉〔影片標題 2026-07-20〕，具體做法我沒有在影片說明欄中寫出。

**6. 風險算術：** 停損 10%，只需再賺約 11% 就能回本；但虧損 50%，則需要賺回 100%。因此，停損紀律永遠比猜對方向更重要。〔說明欄 2026-06-18（精華出處 2026-06-02 直播）〕

- [ ] 日內波的單，13:15 前有沒有平倉？
- [ ] 今天有沒有凹單？（有的話，這是大賠的起點）

## 5.12　放空的三步驟（說明欄）

### 這是什麼

當沖放空的篩選流程，說明欄寫成三步驟，使用的軟體是籌碼 K 線與盤中當沖神器。〔說明欄 2025-09-27（精華出處 2025-08-05 直播）〕

### 怎麼做

**第一步：鎖定高周轉率標的，確保流動性。** 用軟體的「周轉率」與「昨日漲跌幅」欄位篩選；高周轉率代表流動性高；即使市場整體周轉率不高，也優先選擇相對熱門的標的。

**第二步：識別高壓區標的，確立放空理由。** 放空的關鍵是找到已累積足夠上漲壓力的股票，而不是單純追高殺低。候選：

- 連續多日上漲，特別是連續兩根以上大紅 K，或連續兩三天漲停的股票；
- 反彈衰竭：處於空頭格局中，短線反彈已顯疲態的標的。

切忌倉促：不要只憑一兩個理由就放空；理想的選擇必須是「漲了很多」或「具備多重放空理由」。

**第三步：確認賣壓訊號，並嚴格控管風險。** 務必等待當日轉弱的明確訊號，切勿在行情仍強時逆勢操作。風險規避：**切勿放空剛啟動的「布林通道第一根上漲 K 線」**，因為這往往是趨勢剛發動的訊號。

**搭配強勢盤勢的總則**〔說明欄 2025-09-23（精華出處 2025-08-13 直播）〕：如果大盤非常強勁，做多相對容易，要把精力集中在短線做多；強勢盤勢要避免短空，因為放空非常危險且困難、很容易受傷；避開台指期，因為台積電在台指期權重過高，放空台指期等同放空台積電，所以我會以做多為主，並且選擇放空高股息這類表現較弱的股票。

### 檢查表

- [ ] 周轉率高、流動性夠？
- [ ] 已經漲很多（連兩根大紅 K、連兩三天漲停）或有多重放空理由？
- [ ] 今天已經出現當日轉弱的明確賣壓訊號？
- [ ] 這根不是布林通道的第一根上漲 K？
- [ ] 盤勢是否太強？太強就不做短空。

## 5.13　盤後覆盤：分點、節奏與停損大戶

### 這是什麼

盤中的功課做完，盤後要覆盤。我的方法是看分點的籌碼狀況。〔V10 15:49–16:30〕

### 為什麼這樣做

我常說「做當沖一定要看籌碼」：基本面其實變化沒有太大，但是籌碼變化會很大，你要懂得節奏。〔V10 19:18–19:29〕

### 怎麼做

1. **看今天誰害我賠錢：** 看是哪些分點把它買上去的，或是哪些分點在停損。
2. **停損大戶是來發紅包的：** 假如我做多遇到分點停損，事實上他有可能讓我今天賠錢，但是明天可能就有機會賺錢，因為只要他停損光了，那股票就容易上了。我們常講，停損大戶是來發紅包的，你不要跟他一起停損；你反而是要在他停損完的時候，強力地做多。〔V10 16:03–16:25〕
3. **懂節奏：** 有些股票是紅黑紅黑紅黑，主力一買一賣一買一賣，K 棒就一紅一黑一紅一黑；都看了十次一紅一黑，下次紅的隔天又想做多，我就不曉得你在想什麼。紅紅紅，沿著五日線紅上去，通常會遇到有一天長黑，但你不知道是哪一天。〔V10 19:29–20:05〕
4. **點位：** 散戶最常犯的錯誤是點位有可能最高；用情緒買進，看到主力一直攻就想進去。例如都漲四根了，第五根還要追；都漲到明天要被關了，今天還要買，他就有點 FOMO。〔V10 16:36–16:53；18:05–18:20〕

### 檢查表

- [ ] 今天賠錢的單，是被哪個分點的買賣影響？
- [ ] 分點是在停損嗎？（是的話，明天可能是機會，等他停損完）
- [ ] 這檔股票的節奏是紅黑紅黑，還是紅紅紅？我明天的方向有道理嗎？
- [ ] 我進場的點位，是不是別人的高點？

## 5.15　一日當沖流程與總檢查表

### 一日流程（我的順序）

| 時段 | 動作 | 對應章節 |
|---|---|---|
| 盤後（前一晚） | 看分點，了解誰在停損、誰在買；選出量大、波動大、前一天有大漲的熱門題材股 | 5.3、5.13 |
| 盤前 | 觀察試撮張數、期貨有沒有跟、正逆價差比；掛價賣高買低 | 5.4 |
| 開盤前決定 | 今天是黑 K 還是紅 K（順大勢）；日內波還是 Tick 流 | 5.8、5.9 |
| 盤中 | 用連次連量找竭盡：買盤竭盡去空、賣盤竭盡去買 | 5.5～5.7 |
| 盤中停損 | 反向竭盡點回補；最大停損約 5%；停損 % 設大、張數放小 | 5.11 |
| 13:15 前 | 日內波部位停損平倉 | 5.8、5.11 |
| 盤後 | 覆盤：分點、節奏、停損大戶 | 5.13 |

### 總檢查表（可照做的是／否）

**盤前**
- [ ] 標的日均量 ≥ 3,000 張、前一天有大漲、是熱門題材？
- [ ] 月線與布林通道方向是否支持今天的強度預期？
- [ ] 試撮有沒有異常（期貨沒動卻漲停、59 分後委買急減）？
- [ ] 正逆價差比偏多還是偏空？
- [ ] 今天的大方向（黑 K／紅 K）已經決定？

**盤中**
- [ ] 連次達 ±10（有音效）？
- [ ] 連量同方向亮燈？
- [ ] 是不是剛好轉色（紅→綠＝買盤竭盡；綠→紅＝賣盤竭盡）？
- [ ] 方向與今天的大勢一致？
- [ ] 停損點設在反向竭盡點、最大約 5%？

**出場與風控**
- [ ] 有反向竭盡就回補（即使沒到成本）？
- [ ] 張數是賺錢後才放大的？
- [ ] 日內波 13:15 前平倉？
- [ ] 沒有凹單？

**盤後**
- [ ] 看過分點，知道誰在買、誰在停損？
- [ ] 明天的方向有根據（節奏、籌碼），不是情緒？
