# book/ 目錄說明

這裡是《小哥的投資體系》的**編輯中間稿**，讀者不需要看。正式版本是上一層的：

- `xiaoge-system-book.md`（主冊：第00–11部＋附錄 A）
- `xiaoge-book-vol2-columns.md`（補冊一：CMoney 專欄）
- `xiaoge-book-vol3-lives.md`（補冊二：直播）
- `xiaoge-book-vol4-shows.md`（補冊三：早年直播與節目 2018–2023）
- `xiaoge-book-appendix-video-map.md`（影片主題地圖）

`part_*.md`、`supplement_*.md` 是分部撰寫與稽核時的中間稿（出處仍是句內標記，與正式版不同）；`cards/` 是導讀與重點卡。正式版若與中間稿不同，以正式版為準。
