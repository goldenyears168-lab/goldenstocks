## 本部在我的總管線裡的位置

我做每一筆交易，都走同一條線：

> 大盤環境 → 清單（每日／每週）→ 形態確認 → 籌碼確認 → 價值／意圖確認 → 工具選擇 → 扳機 → 出場 → 風控

辭典不是新的一格，而是把這條線上每一格用到的詞放在一起。我的做法是：先把詞的意思講對，再談怎麼用。同一個詞如果每個人講的意思不一樣，後面的流程就會走歪，所以我寧可把詞固定下來。

1. 遇到不確定的詞，先查本部，再回到對應的章節看完整的做法。

3. 我沒有在影片中說明的細節（例如某個欄位背後的算式），這本辭典不會補，也請你不要自己補。

## 9.1　形態與技術

### 這是什麼、為什麼

形態的詞，是用來回答一個問題：「這檔現在是多頭還是空頭，在山的哪一邊？」我的原則是：你假如可以分辨股票是空頭還是多頭，做交易就很簡單了，至少就贏了一半。〔V1 24:53〕

### 詞條

| 術語 | 我的定義 | 出處 |
|---|---|---|
| 布林通道（布林軌道、保力加通道） | 中軌＝20 日簡單移動平均，上軌、下軌＝中軌加減 2 個標準差；倍數一律用 2.0 | 〔V1 6:13–7:00〕 |
| 通道頂／通道底 | 上軌、下軌的白話說法 | 〔V1 8:50〕 |
| 帶寬 | 上通道除以下通道再減 1；小於 5% 是非常窄，5～10% 是普通窄，10% 左右正常，20% 以上算寬 | 〔V1 7:50–8:20〕 |
| 大帶寬／窄帶寬 | 帶寬大時上軌是壓力；帶寬窄時上軌是「等突破」 | 〔V1 7:20–7:49〕 |
| 通道斜率（上通道斜率） | 上通道價格的逐日變化率；3% 以上就是飆股；我反對用「角度」來看 | 〔V1 10:35–12:33〕、〔官方畫面〕當沖神器欄位「上通斜率」 |

## 9.2　籌碼

### 這是什麼、為什麼

籌碼的詞，是用來回答：「有沒有人在推？誰在推？誰在跑？」關鍵分點、主力、投信，各自代表不同的人，不能混著講。

### 詞條

| 術語 | 我的定義 | 出處 |
|---|---|---|
| 關鍵分點 | 長期獲利、比主力先進場的券商分點（內部人、公司派、地緣關係）；他們買就是進場訊號，賣就是出場訊號 | 〔V1 13:43–13:57〕、〔V3 10:54–11:20〕 |
| 內部人／公司派／老闆 | 關鍵分點背後的主體；我說「老闆企圖很重要」 | 〔V1 13:55〕、〔V3 17:40〕 |
| 主力（買賣超） | 籌碼K線上的主力買賣超；當沖神器畫面有「主 1」「主 5」「主 10」欄，算法我沒有在影片中說明 | 〔V6 22:04〕、〔官方畫面〕 |
| 主力籌碼集中度 | 看主力買超那一根的籌碼集中度，至少要有 10%；我覺得有 10% 而且連續，很有可能低點就出現了 | 〔V6 22:54–23:11〕 |
| 主投買／主投賣 | 主力與投信同方向；主力賣、投信買不算，因為投信可能是被出貨 | 〔V1 32:09–32:37〕 |
| 前 15 大分點 | 籌碼K線上買賣超的前 15 名分點 | 〔V6 5:05〕 |
| 集保戶數 | 集保股權分散表的戶數；下降是沉澱，上升是散戶增加 | 〔V1 15:45–15:58〕、〔V8〕 |
| 大戶持股比 | 集保大戶的持股比例（例：V7 的 60% 降到 50%） | 〔V7 0:36–0:50〕 |
| 申報轉讓 | 內部人事前申報轉讓，是賣出警訊 | 〔V1 33:35–33:50〕 |
| 融資／融資斷頭 | 融資多，後面就慘；斷頭那天才會團結 | 〔V1 22:54–24:21〕 |
| 外資、投信、自營商避險 | 大盤籌碼的三個主體 | 〔V6 3:06–4:48〕 |
| 外資未平倉（4～5 萬口） | 台指期外資的未平倉；我在 2025-06 說它已經到了 4 萬到 5 萬口之多，感覺不穩 | 〔V6 4:33–4:40〕 |
| 00632R（反 1） | 外資買超的是 00632R 時，買的其實是反向，不要看到外資買超就覺得很好 | 〔V6 3:39–4:08〕 |
| 期貨價差單 | 外資買 00632R 會讓價差單轉負 | 〔V6 3:52–3:55〕 |
| 台人 | 我說：外資大買之後，看到台人大賣的時候，就要準備出場 | 〔V3 11:40〕 |
| 庫藏股 | 低檔宣布、殖利率高，就可以買；也是公司派的自救工具 | 〔V3 8:14–8:22〕、〔V6 21:20–21:40〕 |

### 檢查表

- [ ] 我看的是「關鍵分點」，還是只看到買超第一名？（兩者不同，見 9.10）
- [ ] 主力買超有沒有達 10% 而且連續？
- [ ] 主力和投信同方向了嗎？
- [ ] 集保戶數與大戶持股的方向有沒有確認？
- [ ] 有沒有申報轉讓的訊息？

## 9.3　價值與基本面

### 這是什麼、為什麼

價值的詞，是回答「這檔值不值得抱、公司派想不想拉」。我為殖利率而買的時候，只在殖利率夠高、配息穩定時才買；殖利率不到門檻，就只是圖價差。

### 詞條

| 術語 | 我的定義 | 出處 |
|---|---|---|
| 殖利率 5% 以上 | 為了殖利率而買的門檻；低於 5% 就只圖價差；比較對象是當時約 4% 的美國 10 年期公債 | 〔V3 10:12–10:40〕 |
| 配息穩定（至少 3 年） | 每年都配息就是每年都賺；要看含疫情前的年份 | 〔V3 9:00–10:12〕 |
| 景氣循環股／曇花一現殖利率 | 例如陽明的 33% 殖利率；這種不能買 | 〔V3 1:40–3:08〕 |
| 營收 YOY | 落後指標；低點翻正，外資就會追進 | 〔V3 11:20–12:50〕 |
| 殖利率出場（低於 4%） | 價格上漲使殖利率跌破 4%，就想出場 | 〔V3 13:35–14:20〕 |
| 可轉債 CB（低於 100／120 以上） | 用可轉債的報價感測公司派有沒有拉抬的意圖 | 〔V3 15:56–16:22〕 |
| CBAS | 可轉債資產交換 | 〔V3 15:55〕 |

### 檢查表

- [ ] 殖利率有沒有 5% 以上？
- [ ] 配息是否至少連續 3 年？
- [ ] 是不是景氣循環股的一次性高殖利率？
- [ ] 持有中，殖利率有沒有跌破 4%？

## 9.4　事件與 ETF

### 這是什麼、為什麼

事件型交易是 1～3 天的短策略（V2 是我的「個股事件獲利王」軟體介紹片，由小秘書示範介面）。ETF 調整成分股的時候，投信與外資的行為有規律，我把利用這個規律賺價差的做法叫做「吃豆腐」。

### 詞條

| 術語 | 我的定義 | 出處 |
|---|---|---|
| 吃豆腐（吃投信豆腐） | 利用 ETF 調整時投信與外資的行為差，賺價差 | 〔V6 全段〕 |
| 豆干（薄）／百頁豆腐（厚） | 豆干是隔天了結的短線豆腐，百頁豆腐是波段的豆腐 | 〔V6 9:53–9:59、18:45–18:49、24:20–24:35〕 |
| 外資發紅包技法 | 外資在最後一盤倒貨、投信盤中慢慢買，我就買最後一盤、隔天早上賣；我拿萬海的對帳單示範 | 〔V6 14:14–14:31、18:41–19:45〕 |
| 納入／剔除（反向操作） | 和一般人的想法完全相反：被剔除的股票股價在低檔，不要太看衰它（跌深就最大利多），等主力轉買再做多；被納入的股票，高檔主力轉賣之後容易往下修正 | 〔V6 10:13–11:03、24:01–24:16〕 |
| 尾盤急殺買／急拉賣 | 最後幾盤漲跌 2%（建議 3%）時，急殺買、急拉賣，隔日出場 | 〔V6 8:43–9:43〕 |
| 最後一盤 | 收盤前的最後一盤；外資尾盤倒貨常集中在這一盤（例：2 萬 6,635 張） | 〔V6 13:52–14:00〕 |
| 批次程式單 | 投信把大量買單切成小單慢慢買 | 〔V6 13:30–13:37〕 |
| 13:20:59 掛 −2% | 散戶手動版：收盤前掛現價減 2% 買進 | 〔V6 15:32–16:55〕 |
| 自組 ETF | 參考各投信買哪些個股，各取所長，自己組一檔 | 〔V6 26:17–26:42〕 |
| 月月配／申購潮 | 月配 ETF 的話術；申購多的時候就是高點，申購是散戶指標 | 〔V5 16:20–17:35〕 |
| 事件型交易 | 1～3 天的事件策略，包含除息、除權、法說 | 〔V2 0:33–0:41〕 |
| 事件日開高機率 | 歷史上事件當日開高的次數比例（例：萬海 10 次裡 10 次） | 〔V2 1:34–4:35〕 |
| 開盤價打折 | 事件日開得越低，往上跳的空間越大 | 〔V2 1:46–2:00〕 |
| 預期報酬率 | 已知有幾 % 機率開高，買進後大概可以獲利多少 | 〔V2 2:03–2:14〕 |
| 提早佈局／延後出場 | 事件前 1～3 日、事件後 1 日的報酬統計 | 〔V2 2:44–3:30〕 |
| 除權息旺季 | 每年 7 到 9 月 | 〔V2 0:00〕 |

### 檢查表

- [ ] 這次是納入還是剔除？我有等主力轉買（剔除）或留意主力轉賣（納入）嗎？
- [ ] 尾盤的漲跌幅達 2%（建議 3%）了嗎？
- [ ] 我要做的是豆干（隔天了結）還是百頁豆腐（波段）？

## 9.5　衍生品與結算

### 這是什麼、為什麼

衍生品的詞，是回答「用什麼工具做」。同一個看法，可以用現股、股票期貨或權證做；先弄清楚每個工具的單位和成本。

### 詞條

| 術語 | 我的定義 | 出處 |
|---|---|---|
| 股票期貨（股期、個股期） | 單一股票的期貨；每口 2,000 股；8:45 開盤 | 〔V4 全段〕 |
| 級距（1／2／3） | 股票期貨保證金的分級，越活潑的股票收得越高 | 〔V4 8:06–8:30〕 |
| 小型股期（小立光） | 每口 100 股（大型是 2,000 股） | 〔V4 10:50–11:50〕 |
| 結算術（股期） | 每月第 3 個週三 13:00～13:30 的做法；高勝率、無隔夜 | 〔V4 14:46–15:38〕 |
| 正價差／逆價差 | 期貨高於現貨是正價差，低於現貨是逆價差 | 〔V5 27:30–28:00〕 |
| 遠近月組合單／價差單 | 買遠月、空近月，鎖住價差 | 〔V5 28:35–29:30〕 |
| 九月期貨不含除息 | 遠月合約反映除息後的真實價 | 〔V5 12:35–13:45〕 |
| 軋空日（3 月底） | 強制回補潮 | 〔V5 23:27–23:45〕 |
| 裸露多單／約當 | 扣掉避險後的淨曝險；權證要換算成約當現股市值 | 〔V5 4:55–5:40〕 |
| delta／gamma | 權證的敏感度；下跌時會縮小 | 〔V5 9:35–9:50〕 |
| 台指期／小台／保證金 | 避險與日內的工具；我說小台最少準備 15 萬做一口，萬一台積電跌停、期貨跌停，還有時間入金 | 〔V5 24:35–26:30〕 |

### 檢查表

- [ ] 我用的單位對嗎（大型 2,000 股、小型 100 股）？
- [ ] 保證金的級距確認了嗎？
- [ ] 現在是正價差還是逆價差？
- [ ] 部位換算成約當現股市值後，裸露多單是多少？

## 9.6　當沖與盤中工具

### 這是什麼、為什麼

這一組是扳機與出場用的詞。盤中我看的是連次與連量，以及它們轉色的那一刻。

### 連次、連量、音效：官方欄位說明

以下是【盤中當沖神器】說明欄的欄位說明，照原文放在這裡〔說明欄 2024-11-21；2025-07-09～08-06〕：

- **連次**：每 5 秒，內盤大於外盤為 −1 次，每 5 秒外盤大於內盤為 1 次。
- **連量**：每 5 秒內盤成交張數（綠字），每 5 秒外盤成交張數（紅字）。
- **音效**：連次達 −10 次（綠）時會有音效，代表個股急殺出量，伴隨大量連次（負數）、連量（綠色）；此時若突然轉變為紅色量時，代表短線上有機會是賣盤竭盡點，可能向上反彈。反之，連次達 10 次（紅）時會有音效，代表短線客大量買進，伴隨大量連次（正數）、連量（紅色）；此時若突然轉變為綠色量時，代表短線上有機會是買盤竭盡點，可能轉折向下。

## 9.14　容易混淆的幾組詞

這幾組詞，我自己講得很清楚，但最容易被聽錯，這裡一次整理。

**一、雙刀戰法＝兩檔股票的配對。**
雙刀是「兩檔高度連動的股票，一檔做多、一檔做空」，例如十威配、南景配、環波配，用相關係數挑出高度連動股，多空對鎖，目標是穩健獲利〔說明欄 2026-01-27、2026-02-13、2026-04-29〕。我在說明欄提到：「回想 2021 年航運股那波，萬海、長榮、陽明怎麼玩？雙刀下去，一多一空，雖然不一定讓你賺到翻天，但重點是能幫你避開大賠。」績效目標是「只剩下大賺、小賺、小賠，把大賠從字典裡刪掉」〔說明欄 2026-01-31〕。

**二、連次與連量。**
連次是每 5 秒統計一次，外盤獲勝記 1 次、內盤獲勝記 −1 次，我說連到十幾次，代表買盤已經連勝十幾次；連量是每 5 秒的內盤（綠字）或外盤（紅字）成交張數。連次達 ±10 亮燈並有音效，轉色時是竭盡點〔V14 11:36–12:14〕。官方欄位說明照 9.6 的原文。

**三、山的左邊與右邊。**
左邊是山頂還沒出現，可以做多、不空；右邊是山頂已經出現，找機會空、出清〔V1 25:00–28:30〕。

**四、豆干與百頁豆腐。**
豆干是薄的，隔天了結；百頁豆腐是厚的，波段持有〔V6〕。

**五、主力與關鍵分點。**
主力是籌碼K線上的主力買賣超；關鍵分點是長期獲利、比主力先進場的分點。兩個不是同一個詞〔V6 22:04〕、〔V1 13:43〕。
