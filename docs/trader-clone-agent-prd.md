# 複製人代理人 PRD（個股期貨手動流程自動化）

狀態：**規格草案 v0.1**（2026-10-04）。尚未實作、尚未安裝任何 launchd job、不具送單能力。
研究窗：**2026-09-29 → 10-02**（使用者明確要求不採用更早紀錄，流程已改過）。
母體：89 筆手動個股期貨委託 / 21 筆成交 / 18 趟平倉 **+488,984 元**（17 勝 1 敗）。

目標：把使用者已驗證有效的行為變成可重複執行的 SOP，在他**沒時間看盤**時代為盯盤與掛單；
持續提高周轉率與報酬率，並壓低每日／每週報酬的波動。

### 3.2 主排序（兩個量綱的**連乘**，不是相加）

```
R2 ＝ 成交額(全日或5分) 前 25%  ∧  大戶佔比(30分) 前 25%
      覆蓋成交單 39.4%，lift 3.82x
R6 ＝ 兩者都前 50%
      覆蓋 51.5%，lift 2.31x        ← 代理人預設用 R6 當候選池，R2 當高信心卡
```

量能與大戶是**交互作用不是獨立相加**：量能前 25% 內，大戶減散戶 5 分 90.2 vs 隨機基準 54.8
（p=0.0017）；大戶佔比前 25% 內，量能 95.2 vs 64.3（p=0.0002）。

控制住兩個量能項後，**大戶減散戶（5 分）是最強的單一殘差因子**（logit z=+2.75, p=0.006）。
尺度排序經隨機基準對照賽馬：**5 分 ≳ 30 分 ≫ 當日**（30分大戶淨額 p=0.0007、當日 p=0.014–0.039）。
FDR 掃 27 欄有 12 欄 q<0.10；**全部散戶欄都不顯著**（散買參與30m q=0.979）→ 不進分數。

### 3.3 族群內挑誰（兩條獨立判準，可同時加分）

- 族群 = 儀表板 **SUBCAT 細分類**（使用者明確要求不要粗族群）
- 挑**當日漲幅最低**者：命中 60%（p=0.0006）
- 挑**20MA 乖離最小**者：命中 50%（p=0.0022）
- 兩者相關 rho=+0.070 → **獨立，可相加**
- 上升趨勢定義 = **20MA 自己在往上爬**（使用者裁決：不管股價在不在均線上）
- ⚠ SUBCAT 10 組中 9 組的族群性是真的（殘差相關 0.30–0.81 vs 全市場基準 0.134），
  **「伺服器代工」是假族群（0.075）不得使用**

### 3.4 加分項（不是濾網）

| 加分 | 數字 | 使用者裁決 |
|---|---|---|
| 42 檔 AGG 差額**正在變大**（正的變多或負的變少都算） | 5 分增量>0 集中度 0.98x ＝無判別力 | Q10：**當加分項** |
| 距 AGG 差額當日低點 **≤30 分鐘** | 30.0% vs 15.1%、**1.99x、p=0.012** | 唯一超過隨機的大盤條件 |
| 距當日高 −1.14%（p<0.001）／距當日低 +1.96%（p<0.001）；小高點後 2.6 分鐘 | | |

**明確不得當濾網的**（會擋掉賺錢的單）：

## 5. 風控（用保證金，不用檔數）

**檔數是無效的風控單位**：每口保證金從 20,547 元（力積電）到 383,670 元（南電），**18 倍差距**。

### 5.1 三分法

目標各 1/3，容忍度 **±50% 相對** → 各腿 **16.7%〜50.0%**。**收盤前檢查即可，盤中不必即時回正。**

| 腿 | 實測中位 | 合規率 | 偏低 | 偏高 |
|---|---|---|---|---|
| 持倉保證金 | 21.4% | 57.6% | 42.4% | **0.0%** |
| 未成交委託單保證金 | 36.2% | 42.4% | 21.4% | 36.2% |
| 現金 | 44.0% | 46.4% | 15.2% | 38.4% |

**不變量：持倉腿「偏高」永遠是 0%。** 三分法的瓶頸不是檔數不夠，是**新倉成交率只有 48%**。

### 5.2 價格帶口數上限（因為「4 檔」與「1000 元以上」數學上不相容）

1/3 持倉腿 = 58.3 萬（權益 174.9 萬）。每口保證金 = 價格 × 契約股數 × 13.5%。

| 價格帶 | 每口保證金 | 58 萬可放 | 代理人口數上限 |
|---|---|---|---|
| 400–600 | 10.8–16.2 萬 | 3.6–5.4 口 | **4 檔各 1 口**（甜蜜區） |
| 600–900 | 16.2–24.3 萬 | 2.4–3.6 口 | 3 檔 |
| 900–1200 | 24.3–32.4 萬 | 1.8–2.4 口 | **2 檔** |
| >1200 | >32.4 萬 | ≤1.8 口 | **1 檔** |

### 5.3 其他硬限

- 同時最多 **4 檔**（人類注意力上限；實測中位 4、最多 5）
- 持倉保證金 >100 萬 → 強制找「條件最差」的平倉（實測歷史最高 852,322，從未破百萬）
- 單筆最大浮動虧損警戒：**做多 30 分 2.2 檔／60 分 2.8 檔／收盤 3.5 檔**（最壞 −2.08%）

### 5.4 標準差的真相（使用者已裁決接受）

組合標準差 = σ·√((1+(n−1)ρ)/n)。單筆 σ=2.153%，族群內殘差相關 **ρ=0.659**。

| 同時 n 筆 | ρ=0 獨立 | ρ=0.134 跨族群 | **ρ=0.659 同族群** |
|---|---|---|---|
| 4 | 1.077% | 1.275% | **1.858%** |
| 10 | 0.681% | 1.011% | **1.793%** |

**變異數地板 = σ√ρ = 1.748%**，n→∞ 也降不過。
10 筆同族群只降 17%（跨族群 53%、獨立 68%）。
**使用者 Q9 選 (a)：集中在 1–2 個風口族群、接受 1.75% 地板、靠勝率撐。**
→ 代理人**不得**以「分散降波動」為理由否決集中度；但必須在日報明示當前 ρ 與理論地板。

## 6. 持倉狀態追蹤與出場

每個持倉必須存一筆**進場快照**（使用者要求「每一個持倉都要記錄原因」）：

```
entry_snapshot = {
  大戶佔比30分, 大戶淨額5分, 大戶減散戶5分, 量能, 族群,
  族群內漲幅排名, 族群內20MA乖離排名, 距當日高%, 距當日低%,
  AGG差額, AGG差額5分增量, 距AGG低點分鐘,
  進場理由文字（出卡時產生，原封不動存下）
}
```

### 6.1 狀態距離（決定「先平誰」）

使用者 Q11 裁決：**三個一起看**。

```
d = |z(大戶佔比30分) − z₀| + |z(族群內漲幅排名) − z₀| + |z(距當日高%) − z₀|
```
取 d 最大者先平（＝跟進場當時差距最大的，不是絕對分數最低的）。

### 6.2 出場觸發（任一成立 → 出卡）

| # | 觸發 | 備註 |
|---|---|---|
| E1 | 進場理由已完成任務（族群內落後差額縮小一半以上） | 基準 = **族群內今日漲幅差距**；例：南電 10/02 進場落後景碩 3.12pp → 1.56pp 算完成。**完成不等於立刻平倉**（使用者：不急著平，可掛高價排隊） |
| E2 | 當下明顯不利、接近成立做空條件 | 條件 = §3 的反向 |
| E3 | 有更好標的成交 ∧ E1 已成立 → 回復三分法 | |
| E4 | 持倉保證金 >100 萬 → 平 d 最大者 | |
| E5 | **13:25 強制平倉**（放棄排隊） | §4.2 的護欄 |

### 6.3 不要太早跑（已驗證）

- 最大浮動獲利到收盤 **+1.127%**，實際只實現 **+0.556%** → **只吃到一半**
- 續抱 2 小時 +0.867%／勝率 80%，vs 換檔追價 +0.379%／62%
- 續抱到收盤 +0.815%／75%，vs 換檔 +0.344%／54%
→ **代理人預設續抱，換檔需要 E1–E4 明確成立。**
