# 如何新增警示

###### 2016-01-11 09:37:51

複製連結

[video/embed](https://www.youtube.com/embed/-u4PmugZasI?rel=0&amp;wmode=transparent)

[![XS策略雷達_01_a](../images/2eaf126389.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/XS策略雷達_01_a.png)在[XQ全球贏家的臉書專頁](https://www.facebook.com/XQ全球贏家-178222061342)內我們會常常會分享一些警示腳本。現在就為你示範如何把文章內的腳本設定成策略雷達的操作步驟。 首先，我們要從文章複製腳本的程式碼。這邊我們以[糾結均線突破](https://www.xq.com.tw/xstrader/?s=糾結均線突破)做範例。 打開網頁之後，可以看到圖文並茂的說明。每篇可都是專家們的心血，值得你再三研究。不過我們今天是來教怎麼樣把腳本變成可以執行的策略雷達，所以，請往下找到程式碼的位置。 在每篇文章中，程式碼都是以獨立區塊顯示的，點擊右上角的**標記程式碼**之後，系統會自動幫你選取要複製的程式碼。請利用右鍵選單將程式碼複製一份下來。 [![radar07](../images/8e5a4139a9.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar07.png) 

### **步驟二：開啟XScript編輯器**

接下來，回到XQ、打開XScript編輯器。 從主選單的 策略→XScript編輯器 [![indicator23](../images/71acac759a.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/indicator23.png)XScript編輯器的版面配置如下：

- 功能列：功能包括「檔案」、「編輯」、「檢視」、「編譯」、「視窗」、「說明」。
- 工具列：常用功能可直接點選工具列上的按鈕作操作。
- 公式區：提供樹狀或清單檢示所有公式。
- 編輯區：公式腳本的編輯區。
- 屬性區：顯示所選公式的屬性值。
- 訊息區：顯示系統或除錯訊息。
[![indicator32](../images/dbf93bd07a.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/indicator32.png) 

### **步驟三：新增警示腳本**

接下來我們來新增一個警示腳本 1. 點擊工具列上的"新增"[![indicator33](../images/761f7124eb.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/indicator33.png)，會出現新增腳本視窗XS腳本一共有四種類型：

- 指標：可以用於技術分析繪製自訂指標
- 選股：可以用於**選股中心**做為選股條件
- 警示：可以用於**策略雷達**做為警示條件
- 函數：如果是會很常重複使用的程式碼，寫成函數腳本後可以被其他腳本引用
2. 選擇警示腳本 3. 在名稱欄填入「糾結均線突破」 4. 確認新增 [![radar08](../images/487b40935b.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar08.png)5. 在編輯區上剛剛複製的程式碼 6. 點擊工具列上的"編譯" [![indicator34](../images/f770f34d97.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/indicator34.png) 或按下**F6**編譯腳本 [![radar09](../images/56600561c2.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar09.png)當訊息視窗顯示**編譯成功**的訊息時，就完成新增腳本的動作。如果有錯誤訊息出現，請檢查腳本是否正確。 [![radar10](../images/03a331ca15.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar10.png) 

### **步驟四：加入策略雷達**

現在我們要把寫好的警示腳本放到策略雷達中執行 1. 在寫好的警示腳本上按滑鼠右鍵，可以叫出右鍵選單，選擇**加入策略雷達**，系統會自動開啟新增策略雷達視窗。 [![radar11](../images/268f303e29.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar11.png)2. 設定要監控的商品。 [![radar03](../images/025abd1514.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar03-1.jpg)3. 點擊**加入**，警示腳本就已經加入策略雷達並開始執行。 [![radar13](../images/ca201797bf.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar13.png)注意到策略雷達現在前面亮著的綠燈了嗎？燈號代表著策略雷達執行狀態，一共有四種：綠燈 [![radar14](../images/9a8db232cf.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar14.png)：正常執行。紅燈 [![radar15](../images/8e8c94b311.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar15.png)：執行出現錯誤。黃燈 [![radar16](../images/4756677f5a.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar16.png)：部份商品正常執行，部份商品出現執行異常。灰燈 [![radar17](../images/6a6975520a.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/radar17.png)：停止執行。OK，到這裡，如果警示正常執行的話，你就不用盯著螢幕看了，等到有符合警示條件的商品出現時，系統就會跳出警示視窗。[##### 前一篇
