# 籌碼分析

###### 2025-08-18 13:30:59

複製連結

「籌碼分析」是除了「技術分析」及「基本分析」外，市場普遍用在股票分析的另類顯學。 為什麼「籌碼分析」這麼受大家歡迎呢？原因不外乎：籌碼是錢堆出來的，不會有作假的問題；還有主力資金比較雄厚，有影響股價的能力，所以跟著他們走，勝率會提高。 XQ推出的【籌碼分析模組】，就是秉持研究籌碼，找出主力的思維下，提供各式各樣的分析工具給大家使用。
