# Log Viewer 使用全攻略：XS Print 紀錄集中檢視、搜尋過濾與執行比對

###### 2026-08-10 16:32:58

複製連結

過去在 XS 中除錯時，Print 的內容大多只能輸出成檔案，使用者必須另外開啟編輯器檢視，才能確認腳本跑得對不對。此次改版提供新的「Log Viewer」介面，讓您不用另外開檔案，就能直接在 XQ 內檢視各種 XS 執行時所產生的 Print 內容，並且能搜尋、過濾、比對不同執行結果，讓除錯流程更順手。 以下說明分為三個部分：Print 行為的改變、Log Viewer 介面怎麼用，以及如果您仍需要把資料輸出成檔案時該怎麼做。 

## **1. Print 行為的改變**

這是本次更新最需要留意的地方。Log Viewer 上線後，Print 的行為會依照您是否有指定 File(..) 參數而不同：

- **Print 沒有指定 File(..)**：將不再產生檔案。Print 的內容改為輸出到 Log Viewer，您直接在 Log Viewer 介面中檢視即可。
- **Print 有指定 File(..)**：維持目前的行為，仍然會產生檔案；同時，這些 Print 內容也會一併出現在 Log Viewer 介面中。
也就是說，不論您的 Print 是否有指定檔名，所有 Print 內容都可以在 Log Viewer 中，以「執行紀錄」的方式檢視，與您指定的檔名沒有任何關係。整體的方向，是希望您最終都能透過 Log Viewer 來檢視 Print 的輸出。 此外，XQ IDE 內原本的「執行」tab 也會一併移除，其原本顯示 Print 的功能由 Log Viewer 取代。 **需注意**：若您原本的腳本沒有指定 File(..)，改版後就不會再產生檔案。如果您的作業流程仰賴這個檔案，需在 Print 時搭配 File 函數指定路徑。 

## **2. Log Viewer 介面與操作**

Log Viewer 是一個獨立的視窗，可以從 IDE 或其他功能介面開啟。介面分為左側的「功能清單區」與右側的「檢視內容區」。 **Log Viewer 整體介面（ 左側功能清單區＋右側檢視內容區 ）** [![](../images/0fa26fadb4.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/01-1.png)

### 2.1 左側功能清單

左側會依照各種 XS 功能類型（ 指標、雷達、選股、自動交易，以及各類回測 ），列出有產出 Print 的物件。

- **指標以外的物件**：保留最近 7 日內有執行過的物件。清單預設只顯示「今日」執行的物件，點「顯示全部」後會依日期分區，顯示 7 日內的全部物件。
- **指標物件**：只顯示「目前開啟、且含有自訂指標的頁面」，並以頁面名稱呈現；不保留歷史紀錄。
**左側功能清單（ 一 ）** [![](../images/575c7d16ea.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/02-1.png)**左側功能清單（ 二 ）** [![](../images/845663e39c.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/03.png)**左側功能清單（ 三 ）** [![](../images/0745b72596.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/04.png)清單操作重點：

- **搜尋**：即打即搜，比對範圍包含策略名稱、頁面名稱，以及頁面內的指標名稱。
- **排序**：可依「更新時間」（ 預設 ）或「名稱」排序。
- 清單每次只展開一個分類，點開另一個分類時會自動收合原本的分類，避免佔滿整個清單區。
- 清單中的項目按右鍵可開啟選單（ 在新分頁開啟、在分割畫面開啟、獨立成一個視窗等 ）。
指標物件較為特別：因為指標沒有明確的啟動 ／ 停止時間，會隨著頁面切換商品、頻率而不斷更新紀錄。因此 Log Viewer 只顯示「目前頁面上」的自訂指標紀錄，不保留歷史資訊。

### 2.2 右側檢視內容區

點擊左側的項目後，右側會以頁籤開啟該項目的紀錄內容。

- 可同時開啟多個頁籤檢視的內容；頁籤可拖曳調整順序，也可拖曳出去成為獨立視窗。
- 左上方工具列有「執行紀錄選單」，以下拉方式列出該物件的每一次執行紀錄（ 例如雷達每次啟動、回測每次執行 ）。執行中的紀錄會亮燈提示，並排在最前面。您可切換不同執行紀錄，檢視各次的 Print 內容。
**執行紀錄選單（ 下拉切換各次執行紀錄 ）** [![](../images/45736a7358.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/05.png)紀錄內容以列表呈現，一行代表一筆 Print，提供下列欄位：

 **欄位** | **說明** |

 **列編號** | 最左側的編號，由 1 開始。 |

 **時間** | Print 呼叫時的系統時間；若為回測 ／ 選股，則顯示該根 bar 的日期時間。 |

 **商品** | 產生這筆 Print 的商品。 |

 **腳本名稱（ 檔名 ）** | 產生這筆 Print 的腳本名稱，方便分辨 Print 來源（ 預設不顯示 ）。 |

 **行號** | 產生這筆 Print 的指令在腳本內的行號（ 預設不顯示 ）。 |

 **訊息** | Print 的內容，以固定寬度字型顯示。 |

內容區的常用功能：

 **功能** | **說明** |

 **顯示欄位** | 可自行選擇要顯示哪些欄位，並可「釘選」欄位使其置左固定、不受橫向捲動影響。預設「時間」、「商品」為釘選並顯示，「腳本名稱」、「行號」預設不顯示。 |

 **搜尋（ Ctrl ＋ F ）** | 即打即搜，符合的內容會 highlight，並顯示符合總數與目前位置，可用上一個 ／ 下一個（ 或鍵盤上下鍵 ）快速跳轉。 |

 **過濾** | 只保留符合條件的內容（ 以行為單位 ）。可用「文字過濾」，也可點選「商品過濾」只看單一商品；商品過濾時工具列會顯示商品 tag，可在不同商品間快速切換，點「全部」即回到未過濾狀態。 |

 **複製** | 支援選取文字或整行（ Shift ＋ 點擊選取多行 ）後複製，整行複製為 CSV 格式；支援全選（ Ctrl ＋ A ）。 |

 **字級** | 可放大 ／ 縮小（ Ctrl ＋ + ／ - ），或依系統設定。 |

**搜尋與過濾功能（ highlight 與商品 tag ）** [![](../images/9f0b1e998c.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/06.png)

### 2.3 分割檢視

當您修改腳本後，常會想比對「修改前」與「修改後」的 Print log。Log Viewer 支援**分割檢視**，可將右側檢視區分割為左右兩邊，分別開啟不同的物件或同一物件的不同執行紀錄來對照。 對頁籤點右鍵即可開啟分割；兩邊分割各有自己的頁籤，頁籤可跨分割拖曳。左右兩邊即使開啟同一個物件，也可以各自顯示不同的執行紀錄或過濾不同商品，不需同步。 **分割檢視（ 左右對照不同執行紀錄 ）** [![](../images/834891627b.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/07.png)

### 2.4 物件獨立視窗

您可以將某個物件頁籤拖曳出來成為獨立視窗，只顯示單一物件的 Print 內容，方便長時間單獨盯著某個物件的 log。獨立視窗支援排序、選擇顯示欄位、字體縮放、搜尋、過濾、複製等功能（ 設定與主視窗各自獨立 ），但不支援分割頁面。獨立視窗也可以再拖回主視窗，併入成為其中一個頁籤。

### 2.5 各 XS 介面的 Log Viewer 入口

分為「開啟 Log」和「Log Viewer」兩種，前者在打開 Log Viewer 後會自動開啟對應功能 ／ 策略的紀錄，後者會在開啟 Log Viewer 後停留在首頁。 **自動交易的 Log Viewer 入口** [![](../images/b7a9c40cf6.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/08.png)**策略雷達的 Log Viewer 入口** [![](../images/9b0f0f2030.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/09.png)**選股中心的 Log Viewer 入口** [![](../images/0f8832bc97.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/10.png)**技術線圖的 Log Viewer 入口** [![](../images/8e537052a7.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/11.png)**XS 編輯器的 Log Viewer 入口** [![](../images/be7745c287.png)](https://www.xq.com.tw/wp-content/uploads/2026/08/12.png) 

## **3. 需要輸出檔案時該怎麼做**

如前所述，改版後只要 Print 沒有指定 File(..) 參數，就不會再產生檔案。若您確實需要把 Print 的資料輸出成檔案，請在 Print 中搭配使用 File 函數指定路徑，系統就會在對應路徑的檔案夾中產生檔案，同時內容也會出現在 Log Viewer 中。 File 函數的用法與參數，請參考 [官方說明](https://xshelp.xq.com.tw/XSHelp/?HelpName=File&group=GENERALFUNC)。 

## **4. 使用時的注意事項**

- **保留期限**：Log Viewer 的紀錄僅保留最近 7 日內的資料，超過期限的紀錄會被清除。未來會開放使用者自行設定保留期限。
- **顯示筆數上限**：基於效能考量，每個物件與 Log Viewer 檢視都有筆數上限。當紀錄超過上限時，畫面上較舊的資料會被較新的資料擠出而不再顯示。若您透過「商品過濾」只看單一商品，該商品在上限內的完整紀錄仍可檢視（ 需注意超出過濾前上限筆數的資料不會有列編號 ）。
- **每行字數限制**：每一筆 Print 的文字長度有上限，超過的部分會被截斷。
- **指標只看當下**：指標物件不保留歷史紀錄，需檢視特定商品 ／ 頻率的 log，請直接切換到該商品 ／ 頻率查看即時內容。若需要備份可使用 File 函數。
- **頁籤內容失效**：若某物件 Tab 已開啟，但對應資料已消失（ 例如指標已從畫面移除、或歷史 log 因換日被清除 ），該畫面會停留、不再更新；關閉或離開後就無法再開啟。
 

## **結語**

Log Viewer 把 XS 各功能的 Print 輸出集中到同一個介面，從此除錯不必再開啟外部檔案：透過執行紀錄選單可以回看每一次執行的結果，搭配搜尋、過濾與分割檢視，能快速比對修改前後的差異。唯一要留意的是 Print 行為的改變——沒有指定 File(..) 的 Print 將不再產生檔案，若您的作業流程仰賴輸出檔案，記得在 Print 中搭配 File 函數指定路徑。[##### 前一篇
