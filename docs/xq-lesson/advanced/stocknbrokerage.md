# 個股與券商關係

###### 2025-08-18 13:35:05

複製連結

[video/embed](https://www.youtube.com/embed/6udaVTlfSq4?rel=0&amp;wmode=transparent)

透過【籌碼大數據】功能找到個股主力券商分點後，可以將其加入自選或追蹤券商，方便之後運用分析。 例如在【個股進階籌碼】，券商名稱滑鼠右鍵及券商名稱欄位[+]按鈕，有提供「加入自選券商」&「加入追蹤券商」選擇。 [![B1](../images/3f61459245.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/B1.png)選擇「加入追蹤券商」後，券商進出表「屬性」欄位會顯示是否為「追蹤券商」。 [![](../images/a1d92a534b.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/B2-1.png) 透過【券商歷史明細】功能，查看券商買賣此檔股票與損益情形。 選擇依「日期」查詢時，可看每日買進、賣出與損益數值；而依「價格」查詢時，可看進出價位落點，與區間累計損益關係。 [![B3](../images/9d54542b35.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/B3.png) [![B4](../images/38957c3c04.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/B4.png) 另外，我們也可以透過【券商分析】功能，看看我們關注的券商最近還交易什麼股票。 此時，只要點選我們要查的自選券商，就可以進行篩選查詢囉！ [![](../images/555c1f5fa2.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/B5-1.png)[##### 前一篇
