# 如何備份、移轉XQ資料

###### 2025-08-18 11:29:16

複製連結

[video/embed](https://www.youtube.com/embed/znqTVlcfy-4?rel=0&amp;wmode=transparent)

1. 請先執行功能表的「設定→備份程式」，系統會備份「User」和「XS」資料夾（在XQ程式安裝路徑「C:\SysJust\XQLite\Backup\備份日期\XQ版號\User、XS資料夾）。 2. 在B電腦先安裝XQ全球贏家完成後，再將以上A電腦的備份檔案 「User」folder→覆蓋至B電腦 C:\SysJust\XQLite\User 「XS」folder→覆蓋至B電腦 C:\SysJust\XQLite\XS ※ 註： 「XS」folder 中是 自訂的指標/選股腳本/排程/函數/腳本/ →XS相關都在這 「User」folder 中是 自訂頁面/畫面中的註解和畫線→非XS放在這 3. XQ資料是by帳號儲存，用以上方式備份出來的檔案，可以直接匯入/或還原到B電腦相同帳號內，不同帳號無法使用。 若需提供其他帳號使用，可以依需求使用系統功能「匯出頁面」或「匯出腳本」方式單獨匯出/匯入使用，則無帳號限制。[##### 前一篇
