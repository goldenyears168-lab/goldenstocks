# 技術分析：主圖K棒顏色設定說明

###### 2025-08-18 11:47:59

複製連結

XQ 支援了主圖K棒的顏色設定功能，大家可以依據自己的使用習慣來調整K棒的顏色。 以下是本篇文章的目錄： [一、自訂K棒顏色的入口](https://www.xq.com.tw#anchor01) [二、如何自訂K棒顏色](https://www.xq.com.tw#anchor02) [三、K棒顏色及樣式的畫面呈現](https://www.xq.com.tw#anchor03)  

### **一、自訂K棒顏色的入口**

- - - - 在技術分析畫面按滑鼠右鍵，選擇「設定」 [![](../images/fd1a942abc.png)](https://www.xq.com.tw/wp-content/uploads/2024/05/1.png)
- 選擇「主圖指標」頁籤，在「K線」的選項右邊，會顯示目前的預設顏色 [![](../images/05d56d5f0a.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/05/2.jpg)
- 點擊K棒顏色的下拉箭頭，系統就會彈出「自訂K棒顏色」設定 [![](../images/e11efceb27.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/05/3.jpg)
 

### **二、如何自訂K棒顏色**

在「自訂K棒顏色」設定，我們提供了兩種設定模式： **(一) 利用「系統」提供的預設項目來切換K棒顏色** 在「自訂K棒顏色」設定中，左邊是系統提供的預設顏色項目，項目中陳列了目前各種主流K棒顏色的設定，大家可以用滑鼠點擊來切換，並利用右邊的預覽視窗，來確認顏色及K棒樣式是否為自己喜歡的呈現方式。 [![](../images/43ff0632e8.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/05/4.jpg) **(二) 自訂K棒顏色**

- - - - 可以自訂陽線及陰線的K棒實體顏色 [![](../images/abc7d0372f.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/05/5.jpg)
- 可以自訂陽線及陰線的K棒外框顏色 [![](../images/e38c24bc89.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/05/6.jpg)
- 可以利用勾選「填滿實體」的選項，來決定K棒實體為空心或實心 [![](../images/24688a09d9.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/05/7.jpg)
