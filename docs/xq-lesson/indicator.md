# XS自訂指標

###### 2016-01-07 20:47:17

複製連結

[![8-00](images/c47c2197a4.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/8-00.png) 雖然經典的KD、RSI很好用，但現在的市場，交易速度這麼快、變動如此劇烈，要怎麼樣才能迅速驗證新的交易想法？ 為了滿足你這方面的需求，XS提供了「自訂指標」的功能。 自訂指標是除了系統內建的指標之外，由使用者利用XScript語法自行編寫的指標。 透過XS自訂指標，你可以快速在技術分析線圖上驗證新的交易策略與想法。XS自訂指標還能利用一些像是基本資料、籌碼資料等非價量的特殊資料來計算，大幅提高指標勝率，讓你更容易掌握股價轉折的時機。 **使用者可以自行撰寫指標** 你只要將指標的計算邏輯寫在指標腳本當中，就可以放在技術分析線圖上檢視計算的結果。更重要的是，XS自訂指標還能利用一些像是基本資料、籌碼資料等非價量的特殊資料來計算，大幅提高指標勝率，讓你更容易掌握股價轉折的時機。 **內建豐富的系統指標** 還不會XScript語法也沒關係。系統提供近百種內容涵蓋大部份的XQ指標的指標腳本，腳本內容完全透明公開，方便使用者經由熟悉的指標來學習XScript語法。 **專家線上分享、指標永續更新** 你可以利用XS匯出/匯入指標腳本的功能，和股友同好交流分享自訂指標。我們也會不定期在[XQ全球贏家臉書專頁](https://www.facebook.com/XQ全球贏家-178222061342)上分享最新的指標應用，歡迎你加入我們的臉書來取得有關XS的最新訊息。 接下來我們就一一為大家介紹XS自訂指標的使用方式，以及如何自己設計XS自訂指標。請大家繼續看下去。 [##### 前一篇
