# XS自動交易

###### 2020-11-05 10:00:57

複製連結

[![](images/7942828163.png)](https://www.xq.com.tw/wp-content/uploads/2020/10/XSAT_01.png)許多朋友們期盼已久的自動交易功能，經過嘉實資訊同仁們不斷的努力後，正式登場！ 過往我們只能藉由策略雷達的觸發下單設定來進行交易，沒辦法依照觸發時的情境來控制委託的價格以及數量，委託送出之後也不確定是否已經成交，如果想要當沖的話，所需要的設定更是複雜。 這些策略雷達執行交易的問題，在新推出的自動交易系統內，都可以很直覺的完成設定。想要指定委託價格／數量，想要知道成交數量／價格，想要加碼／平倉／翻轉多空部位，這些都可以直接從腳本內完成控制！ **基於XS系統,提供最豐富的欄位** 自動交易系統延續「策略雷達」的優點，能夠取得豐富的盤後數據，以及最即時的盤中數據，包括「籌碼」、「價量」..等，以強力的後盾支援使用者無憂的撰寫策略。 **透過部位指令控制交易方式** 快漲停的股票我要用「市價」追；定存股必須跌到合理價我才用我指定的價格來買，自動交易系統可以讓您按照不同的策略設定特定的交易方式。 **支援交易帳號實際庫存的整合(部位/成本)** 過去策略雷達無法讓腳本抓到「庫存量」、「庫存均價」，使得停損停利策略的撰寫十分繁瑣； 現在您只要使用簡單的語法，XS自動交易系統就會幫您統計出數值。 **獨家手機監控功能** 我是上班族白天不能抱著電腦到處跑，怎麼辦？ 現在您只要在家裡開好XQ全球贏家(電腦版)啟動自動交易程式，就可以串聯XQ全球贏家(手機版)進行監控，讓您隨時可以掌握策略的執行狀態，發生任何突發狀況時可以在第一時間內處理。 **每個策略可以選擇不同券商** A券商在期貨給我的折數比較多! B券商融資融券餘額比較充裕? 自動交易系統可以讓您自由選擇各個策略的對應券商。 **支援回測功能** 想要試試你的祕密策略是否能賺大錢? 先回測看看績效如何再進場操作! 回測功能讓您可以對多檔商品同時回測，設立進場出場策略，最後生成報表分析，一目了然的知道報酬率如何。[##### 前一篇
