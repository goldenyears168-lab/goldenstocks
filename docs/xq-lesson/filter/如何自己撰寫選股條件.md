# 如何自己撰寫選股條件

###### 2016-01-11 10:49:29

複製連結

[video/embed](https://www.youtube.com/embed/tscxWvo7qQ8?rel=0&amp;wmode=transparent)

在前一篇文章內我們學到了如何利用【XS選股中心】內建的欄位/排行條件來建構選股策略，可是萬一系統裡面找不到你想要的條件該怎麼辦？沒有關係，只要透過XScript的語法，你就可以創造你自己獨特的選股邏輯。聽起來是不是很神奇呢？那就讓我們趕快來看看怎麼做吧！ 以下針對操作面做說明。

### 

 

### **步驟一：打開XS編輯器，建立一個選股腳本**

開啟選股中心，點選工具列中的「XS編輯器」按鈕。 [![XSF_01](../images/b40f32de76.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/XSF_01.png)在XS編輯器中，點選「新增」按鈕，建立一個選股腳本，名稱設定為「突破均線」。 [![XSF_02](../images/add7b695e4.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/XSF_02.png)

### 

 

### **步驟二：撰寫選股程式碼**

接著，把突破均線的語法填上，例如：1Input: X(3, "天期"); 2Value1 = Average(Close, X); 3Condition1 = Close > Value1; 4Condition2 = Close[1] < Value1[1]; 5If Condition1 And Condition2 Then Ret = 1;然後，點擊工具列上的「編譯」[![indicator34](../images/f770f34d97.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/indicator34.png)或按下F6編譯腳本， [![XSF_03](../images/8aab5a4136.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/XSF_03.png) 

### **步驟三：加入選股策略**

編譯完成後按右鍵選單，選擇「加入選股策略」。 [![XSF_04](../images/dd4709510c.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/XSF_04.png)這時候系統會把選股中心的畫面叫起來，同時建立一個選股策略，這個策略內只有一個條件，就是剛剛寫的腳本條件。 [![XSF_05](../images/2287408fed.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/XSF_05.png) 【XS選股中心】內建了數百個常見的選股條件/排行條件，通常透過疊積木的方式，就可以輕鬆建構出一個選股策略。現在更厲害的是，你還可以利用XScript自己編寫獨門心法！ 一些常見的篩選條件，加上一點點自己的巧思，正是贏家之所以成為贏家的關鍵。XS將是你投資決策最佳幫手！[##### 前一篇
