# 選股中心基本操作

###### 2016-01-11 10:46:22

複製連結

[video/embed](https://www.youtube.com/embed/5rZM6CG59Sg?rel=0&amp;wmode=transparent)

【XS選股中心】是把選股邏輯轉化成條件式的系統，價、量、財報、籌碼等資料隨你取用，只怕想不到、不怕選不到。 看完影片後應該覺得選股中心的操作一點都不難吧！為了方便大家實做，以下用文字敘述的方式一一說明操作流程：

### 

 

### **步驟一：開啟選股中心**

[![filter01](../images/ccfc640ca1.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter01.png)選股中心的版面配置如下：

- 功能列：所有功能都可直接由功能列上的按鈕作操作。
- 目錄區：可依標籤或目錄的方式檢索現有的選股策略。
- 清單區：列出目前所選的標籤或目錄內的選股策略清單。
- 條件內容區：顯示目前所選的選股策略條件內容。
- 選股結果區：顯示最新的選股結果，以頁籤分隔條件。
- K線預覽
 [![filter02](../images/5dba9a2e98.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter02.png)目錄區中的「標籤」可以讓你快速的篩選選股策略，目前提供以下的選擇方式：

- 全部：列出所有選股策略
- 最新：依選股策略的**建立日期**，列出最新的20個
- 常用：依選股策略的**執行次數**，列出最多的20個
- 每日自動執行：列出所有**啟動每日自動執行**的選股策略
- 最近執行：依選股策略的**執行時間**，列出最新的20個
- 最近匯入：列出最近一次匯入的選股策略
你也可以在搜尋區內輸入文字查詢吻合的選股策略。

### 

 

### **步驟二：執行選股策略**

在目錄區，可以依標籤或目錄來切換清單區內的選股策略清單。 點選「系統→10.大師選股」，右方清單區會列出多位國際大師的選股策略。 [![filter11](../images/db25df4a53.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter11.png)點擊「1003.華倫巴菲特」，可以在條件內容區看到巴菲特的選股條件。 [![filter03](../images/a87bd1b434.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter03.png)接下來，左鍵雙擊「1003.華倫巴菲特」，就會執行這個選股條件並在選股結果區看到篩選結果。 

### **步驟三：檢視選股結果**

執行完的選股策略，會在選股結果區看到篩選結果。 點擊股名或股號，可以在右方看到K線預覽。 雙擊股名或股號，可以將股票帶入個股分析頁面，檢視更多相關資訊。 [![filter04](../images/58ddceab81.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter04.png)

### 

 

### **步驟四：加入自選股**

選出來的股票，我們可以將有興趣的標的加入自選股，方便明天盤中觀察。 只要勾選代碼前的勾選股，再點擊工具列上的 [![filter12](../images/a37a11a9b5.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter12.png) 按鈕，就可以把勾選的股票加入你的自選組合當中。 工具列上的按鈕可以對股票清單進行操作：

- [![filter05](../images/86e3fd6432.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter05.png)：把勾選的股票加入自選股
- [![filter06](../images/75423f9c20.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter06.png)：匯出整份股票清單成excel做進一步分析
- [![filter07](../images/f2a98d74df.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter07.png)：重新執行或停止執行選股策略
- [![filter08](../images/65aa0f22b5.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter08.png)：調整顯示的欄位順序
- [![filter09](../images/55a12356c7.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/filter09.png)：顯示/隱藏K線預覽
