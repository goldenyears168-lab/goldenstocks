# XS策略雷達

###### 2016-01-07 20:44:36

複製連結

[![策略雷達首頁](images/674a256bc1.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/08__00.png)當台股撮合頻率從20秒一撮、5秒一撮，到現在的盤中逐筆撮合，人眼要如何才能追上這快速的變動呢？不必擔心，現在有【XS策略雷達】可以幫你。 【XS策略雷達】是嘉實資訊最新研發完成的盤中即時監控功能。 和以往固定條件的即時選股不同，【XS策略雷達】是完全對使用者開放的高度客製化平台。你可以利用XScript來自訂盤中篩選的條件，並且針對任意的商品組合進行監控，是一個特別針對股票族量身打造的投資利器。

### **即時監控**

全台獨家支援大量股票即時監控，自動篩選過濾符合條件的股票。你再也不用花那麼多的力氣去盯盤，盤中任何重要變化都不會錯過。

### **歷史回測**

台灣首創策略回測平台，支援價量，籌碼等欄位，可同時回測多檔商品，透過報表分析，讓你可以多方面驗證策略的勝率。

### **觸發下單**

策略產生的訊號可以直接觸發下單，從決策到交易都由電腦自動執行。同時支援模擬交易功能，讓你的策略在正式上線實戰前更進一步驗證策略的可靠性。

### **內建百種常見交易策略**

市面上常見的交易策略已為您收集在系統當中，上百種交易策略都可以直接使用。現在就套用上你的自選股，立即體驗策略雷達的超強功能。
