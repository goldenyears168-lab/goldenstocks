## **什麼是「量化交易」？**

別想得太複雜。**「量化交易」的核心，就是把您「主觀的經驗」，變成一套「客觀的SOP」。**

- **主觀交易：** 「我感覺K線好像到底了，好像可以買了。」
- **量化交易：** 「如果KD指標 < 20，且股價站上月線，就符合買進SOP。」
「量化」的本質，就是**把您腦中的交易邏輯「明確化」、SOP化**。 它的最大價值，是讓您在真正投入資金前，可以透過「**回測 (Backtesting)**」功能，用歷史數據驗證您的SOP到底可不可行，並在實戰中輔助您「**克服人性**」（如貪婪與恐懼），紀律地執行您的SOP。

## **破解 3 大迷思：你是否也誤會了量化交易？**

多數人之所以恐懼，是因為對量化交易有三大迷思。

### **迷思一：量化交易 = 一定要會寫程式？**

**答案：錯！這是最大的迷思！** 在過去，您可能需要學 Python 或 C++ 才能執行。但現在，**「量化」不等於「程式」**。 「量化」是一種**策略思維**，「程式」只是一種**執行工具**。 現在的工具（如 XQ 全球贏家）已經提供了「**零程式碼**」的解決方案。例如 XQ 的「**量化積木**」功能，它把所有複雜的選股條件（如「KD黃金交叉」、「投信買超」）都變成了一個個「積木」。 您**不需要寫任何程式**，只需要像「堆積木」一樣，用滑鼠點選、拖拉，就能把您的交易SOP組合起來，並立即執行回測。這讓「量化」的門檻，從「理工博士」降到了「所有會用滑鼠的投資人」。 詳情可參閱➡️[【新手教學】什麼是量化積木？如何用它製作選股策略教學（附範例）](https://www.xq.com.tw/learning/xqblocksbuildstraegy/)

### **迷思二：量化交易 = 數學要超好、要會AI？**

**答案：錯！** 沒錯，華爾街的頂尖量化基金，確實會使用複雜的數學模型或AI。但那**不是**一般投資人需要、適合的量化。 對我們來說，量化交易使用的是「**基礎的邏輯**」，而不是「高深的模型」。

- 「股東權益報酬率(ROE) > 15%」 —— 這是**基本面**
- 「股價站上 20 日均線」 —— 這是**技術面**
- 「本益比 < 12倍」 —— 這是**價值面**
這些您本來就在用的指標，本身就是「量化」的基礎。您不需要發明新策略、模型，**您只需要把您懂的指標，系統化地組合起來**，這就是最實用、最有效的量化交易。

### **迷思三：量化交易 = 找到「聖杯」全自動躺著賺？**

**答案：錯！這是最危險的迷思。** 量化交易**不是**一個能100%預測未來的「聖杯」，更不是一個設定好就能永遠「全自動躺著賺」的印鈔機。 您應該把量化交易視為一個強大的「**輔助工具**」與「**策略實驗室**」：

- **克服心魔的「紀律SOP」：** 量化系統沒有情緒。當您的SOP發出「賣出」訊號時，它不會像您一樣「凹單」或猶豫。它能幫您**解決「知道該做，但做不到」的人性弱點**。
- **驗證想法的「回測實驗室」：** 您腦中的「獨門戰法」到底有沒有用？別用真錢去試！用量化積木的「回測」功能跑一下，**用數據證明您的策略**在過去五年是賺錢還賠錢，這能幫您省下大量的學費。
