# 功能介紹：什麼是雲端監控？

###### 2024-12-12 16:09:51

複製連結

 [![功能介紹：什麼是雲端監控？](images/08c3b026b8.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/你的段落文字-1-1.png)

## 1. 摘要

雲端監控功能可以讓我們不需要寫程式碼，就可以在盤中即時監控你在每檔個股所設定的條件，條件滿足後，系統會立即傳送訊息到您的電腦 或 手機。雲端監控他可以支援單一股票、自選清單及庫存監控，讓我們提升盯盤效率與便利性。 ▼呼叫方式。從功能列中 「設定」>「我的設定」>「雲端監控」 [![呼叫方式。從功能列中 「設定」>「我的設定」>「雲端監控」](images/8213b4a7c8.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image7-28.png)

## 2. 如何新增警示條件？

雲端監控 除了可以監控單一商品之外，同時也可以針對自選股清單以及庫存進行監控功能。  

### 2.1. 單一商品設定畫面介紹

▼監控單一商品的操作為：輸入商品代碼，然後挑選想要監控的條件。 [![監控單一商品的操作為：輸入商品代碼，然後挑選想要監控的條件。](images/9bfffe0619.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image4-38.png)[![監控單一商品的操作為：輸入商品代碼，然後挑選想要監控的條件。](images/aac34d0390.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image8-23.png) ▼可以點擊條件分類來瀏覽。點擊條件方框即可加入此條件。部分條件可以設定參數，在條件框上會有文字提示，點擊後可以輸入參數。 [![可以點擊條件分類來瀏覽。點擊條件方框即可加入此條件。部分條件可以設定參數，在條件框上會有文字提示，點擊後可以輸入參數。](images/59f4d3df92.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image5-33.png)[![可以點擊條件分類來瀏覽。點擊條件方框即可加入此條件。部分條件可以設定參數，在條件框上會有文字提示，點擊後可以輸入參數。](images/6f56d47a88.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image3-37.png)

### 2.2. 清單監控設定畫面介紹

如果我們希望可以針對一個自選清單內的所有商品同時進行監控的話，該如何進行設定呢?譬如：某一組自選股組合內任一商品上漲2％時通知我，就可以使用清單監控功能。 清單監控功能的基本觀念，是把監控的範圍分成多個「監控區」，我們可以針對每個監控區，放入「要監控的清單」，以及「要監控的條件」，當清單內的任一商品符合指定條件時，系統就會產生通知，而且當清單內的商品有異動時，新加入的商品也會自動被監控。每個監控區可以放入多個清單，方便我們用一樣的邏輯來監控不同的商品來源。 首先，使用者選擇監控區，然後加入要監控的清單。可以監控的清單包含：

- 自選股組合
- 自動選股清單，包括：

- XS選股中心的每日選股清單
- 籌碼分析模組產生的每日選股清單
- 贏家選股策略每日清單
▼使用者選擇監控區，然後加入要監控的清單。可以監控的清單包含： 自選股組合、自動選股清單 [![使用者選擇監控區，然後加入要監控的清單。可以監控的清單包含： 自選股組合、自動選股清單](images/90c8ba4789.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image11-20.png)選擇好清單之後，就可以設定需要監控的條件。 清單監控支援的條件與個股監控類似，使用者可以切換條件分類，然後點擊要加入的條件方框。 ▼選擇好清單之後，就可以設定需要監控的條件。 [![選擇好清單之後，就可以設定需要監控的條件。](images/7900715ca6.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image1-41.png)

### 2.3. 庫存監控設定畫面介紹

除了可以針對指定清單內的商品進行監控之外，使用者也可以使用庫存監控功能來監控交易帳號內的庫存商品。 使用的方式類似清單監控，系統提供多個庫存監控區。我們可以針對每個庫存監控區，放入「要監控的交易帳號」，以及「要監控的條件」，當被監控帳號內的任一庫存商品符合指定條件時，系統就會產生通知。同樣的，如果被監控的交易帳號的庫存商品在盤中發生異動時(例如透過這個帳號買入了一檔新的商品)，這個新加入的商品也會自動被監控。每個庫存監控區可以放入多個帳號，讓使用者可以用一樣的邏輯來監控不同帳號的庫存商品。 支援的庫存帳號有以下限制：

- 支援XQTrade的所有證券帳號，包含模擬交易證券帳號，也就是說庫存監控只支援台股股票商品， 每日開盤前會更新監控帳號的庫存商品，確認監控的範圍。盤中收到成交回報後，會自動更新監控商品(更新間隔約30秒)
 可以針對帳號內的全部庫存商品進行監控，也可以只監控做多的商品，或是只監控做空的商品。也可以點擊右上角的「設定交易帳號」按鈕，登入更多的交易帳號。 ▼設定監控條件的方式與清單監控相同，一樣是點擊條件方框就可以加入。 [![設定監控條件的方式與清單監控相同，一樣是點擊條件方框就可以加入。](images/a438497f88.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image9-23.png)

當條件設定完成後，我們只要觀察警示紀錄頁，看看是否有個股達成條件。 ▼使用系統頁面"綜合看盤"的"自動監控"分頁。 [![使用系統頁面"綜合看盤"的"自動監控"分頁。](images/1aca446759.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image10-22.png)▼使用系統頁面"綜合看盤"的"自動監控"分頁。 [![使用系統頁面"綜合看盤"的"自動監控"分頁。](images/caba3bc5f5.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image6-31.png)
