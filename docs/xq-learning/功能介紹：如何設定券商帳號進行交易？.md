## **1. 摘要**

這篇教學主要介紹如何使用XQ與多家券商串接進行即時交易、如何使用內建模擬交易帳號來測試自己開發的策略，並詳細解說交易帳號設定、下單操作、即時資訊與帳務管理功能。

## **2. 如何在XQ中進行交易**

XQ全球贏家提供「**券商下單」**功能，您可透過券商雙因子認證或API申請，就可直接下單到券商，完整達到**「看盤→策略→下單→回報」**一條龍的服務！ 目前系統提供[20家以上券商](https://www.xq.com.tw/broker.aspx)可供選擇，要與各券商串接下單可參考此篇文章[**XQ 全球贏家與合作券商下單串接合作模式 (即時更新)**](https://www.xq.com.tw/broker/)

## 3. 交易偏好設定

您可以透過交易偏好設定，來設定下單時的預設值與下單保險，以避免下出非預期的單子。

- 進入方式：點選主功能列中「交易」，再點選「交易偏好設定」功能項。
- 交易偏好設定共分為七個頁籤：「證券下單設定、證券保險設定、權證下單設定、權證保險設定、期權下單設定、期權保險設定、關係人交易」。
[![交易偏好設定共分為七個頁籤：「證券下單設定、證券保險設定、權證下單設定、權證保險設定、期權下單設定、期權保險設定、關係人交易」。](images/b89148b73f.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image17-6.png)

## 4. 行情帶下單(直覺式操作)

▼您可以直接在畫面上有報價行情的地方點擊價位，當滑鼠移動到報價上時，圖示會變成下單。 [![您可以直接在畫面上有報價行情的地方點擊價位，當滑鼠移動到報價上時，圖示會變成下單。](images/2fe0496d8b.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/12/image3-1.jpg)▼即時行情帶有目前價位或是五檔價位，最高最低的地方，只要有出現下單的圖示都可以點擊，將價格資訊帶入下單列。雙擊行情報價會將資料帶入下單列，如果原本下單列隱藏也會自動彈出來，您可直接送出下單。 [![即時行情帶有目前價位或是五檔價位，最高最低的地方，只要有出現下單的圖示都可以點擊，將價格資訊帶入下單列。雙擊行情報價會將資料帶入下單列，如果原本下單列隱藏也會自動彈出來，您可直接送出下單。](images/6b8f811a1e.jpg)](https://www.xq.com.tw/wp-content/uploads/2024/12/image14.jpg)▼另外在商品盤勢或是報價組合，右鍵點在商品名稱上時，可以快速選擇"買進/賣出"，點選後也會將資料帶入下單列喔！ [![另外在商品盤勢或是報價組合，右鍵點在商品名稱上時，可以快速選擇"買進/賣出"，點選後也會將資料帶入下單列喔！](images/b2bb4586bc.png)](https://www.xq.com.tw/wp-content/uploads/2024/12/image2-39.png)
