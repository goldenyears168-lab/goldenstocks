# 籌碼選股判斷工具規格（chip_screen）

`scripts/research/chip_screen.py`＋`config/chip_screen.yaml`（標的清單）＋`tests/test_chip_screen.py`。
來源：XQ 全球贏家教學（`docs/xq-tutorial/`）與權證小哥（`docs/warrant-xiaoge/chip-sop-spec.md`）。

```bash
PYTHONPATH=src .venv/bin/python scripts/research/chip_screen.py [--asof YYYY-MM-DD] [--stocks 2330,2303 | --watchlist default] [--write] [--json]
```

唯讀 DB；預設只印出；`--write` 另存 `${DATA_DIR}/chip/screen/chip_screen_{日}.{json,md}`。

## 定位
- 描述盤後籌碼狀態，**不是預測**。各規則尚未單獨驗證（多因子搭配判斷，之後再配驗證）。repo 既有檢定：籌碼 SOP 對隔日收盤無獨立預測力、外資分點跟單無 edge。
- 缺資料＝NA，不補、不拿替代資料推。門檻只定義在腳本 `TH`；標「操作化」＝教學／書沒給數字，我們自己定。

## 流動性閘門（2026-10-26 起）
前 20 日均量 ≥1000 張、均成交值 ≥0.5 億、收盤 ≥10 元三者皆過才下方向結論；未通過者標「流動性不足」並加 W16，方向規則的命中仍列出但不計入結論。
依據：2026-10-22 全市場約 1,959 檔，20 日均量中位數 281 張、均成交值中位數 0.13 億，本閘門約留 27%；專案先例 /inventory ≥3000 萬、xiaoge_chip_daily ≥5000 萬。數字為操作化，可在 `TH` 調。

## 結論邏輯
三組方向訊號：**法人資券（XQ）／分點（小哥，沿用 chip_sop.py）／集保（XQ）**。組內 bull 命中數減 bear 命中數＝組淨向。可用組 <2＝資料不足；組間有正有負＝分歧；同向＝偏多／偏空（≥2 組同向為強、1 組為弱）；全 0＝中性。
價量、處置、爆量、當沖等「特別留意」（W 系列）不計方向。組內同時有多空命中時加 W14（組內互斥）。

## 未實作的 XQ 專家策略（缺資料）
- 不明買盤（扣除散戶買張〔單點單價 <50 萬〕、當沖張、法人買張後的剩餘買盤佔量）：需要分公司×價位的逐筆成交，庫內沒有。
- 投信持股比例 <1.5%、投信持股比例降低最快：庫內沒有投信持股比例。
- 代操資金（前十大綜合券商總公司合計）：需要全分點資料，2026-10-16 起只有前段分點。
- 董監持股、內部人持股、董監質設、申報轉讓：庫內沒有資料表。
- 各策略的勝率／年報酬皆為 XQ 作者自述的回測宣稱，無樣本數與成本說明，本工具只描述是否符合條件。

## 已知限制
- 融資使用率（>60%）、融資維持率：庫內無融資限額／成本線，**不做**。
- 分點：2026-10-16 起只有「前段分點」，不足 chip_sop 閘門的標的，分點組為 NA。
- 處置／注意資料來自 `${DATA_DIR}/disposal/*.csv`，不含當晚尚未寫入的公告。
- 漲跌停為 ±9.5% 近似；報酬用收盤，未還原權息。
