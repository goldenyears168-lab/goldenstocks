## 一、結論先看

1. 儀表板的「選股」不只 `/chips`：至少分四層——盤中逐筆評分（主頁）、日線籌碼與小哥戰法（/chips、/inventory、/xiaoge、/disposal、/futflow）、複製人與紙上帳的進出場、以及不在頁面上的排程選股信。
2. **沒有統一的現貨流動性門檻。** 各處各用各的：期貨名目成交金額 ≥3 億（42 檔池）、20 日均成交值 ≥3000 萬（/inventory）、≥5000 萬（xiaoge_chip_daily）、單日 ≥500 張且 ≥10 元（chip-daily-brief）、單日成交額 ≥20 億（limitup-fade）、3000 張（只標示的 R27 與竭盡灰化）。複製人與紙上帳完全沒有絕對量門檻。
3. **沒有一條日線籌碼規則有「樣本外有 edge」的結論。** 唯一有真 OOS 正結果的是 limitup-fade（每筆 +0.79%，cluster-t 5.07），卡在滑價與當沖資格。
4. 儀表板盤中評分裡，優勢多半在「延遲 1 桶後明顯縮水」（買賣價彈跳），不是可執行 alpha。
