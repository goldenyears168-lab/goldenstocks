## 1. 原則
1. **語意優先於顏色**：代幣（design token）依「用途」命名（`--price-up`），不依顏色命名（`--red`）。
2. **價格色、狀態色、分組色三族互不混用**：價格色只用在漲跌／買賣方向；狀態色只用在系統好壞；分組色只用在資料分組。
3. **顏色之外要有第二線索**：漲跌一律帶 `+／−` 符號（或 ▲▼），錯誤帶圖示或文字，不只靠紅綠。
4. **單一來源**：樣式放在 `.css` 檔，由伺服器提供；頁面只引用變數，不直接寫十六進位顏色。
5. **對比度**：文字與圖形顏色對底色 `#0d1117` 至少 4.5:1（WCAG AA）。

## 3. 字型與數字
- 基準字級 12px；表頭副標 9–10px；說明文字最小 11px。
- 數字欄：靠右對齊、同欄小數位數固定、`font-variant-numeric: tabular-nums`。
- 金額單位：台幣金額以「萬」為主要單位（與主頁一致）；口數／張數為輔助欄。
- 區間用語：「全日」「5分」「30分」；期貨以「本盤」代替「全日」。
- 介面用語一律繁中（日盤、夜盤、盤別），不出現英文 `session`。

## 4. 共用元件（要有統一寫法）
表格（固定表頭、小字副標、`title` 說明）、卡片、徽章（`.badge` 的 info／ok／warn）、警示列（`.warnv` + ⚠）、說明框（`.disc`）、盤別狀態標籤（日盤進行中／夜盤進行中／盤後定格）、導覽列。
