# 大戶隔夜跳空訊號 — 設計凍結規格（frozen spec）

**狀態：觀察/前瞻測試（forward-test）專用，尚未採納、不下實彈。** 本規格記錄經 13 路 adversarial 檢定 + 兩支形式測試（2026-09-05）驗證留下的設計選擇與被否決的加法，作為前瞻測試與未來若採納時的護欄。判決 SSOT：記憶 `biglot-overnight-limitup-proxy-verdict.md`。發言紀律 SSOT：`docs/analysis-claim-discipline.md`。

---

## 0. 一句話定位

訊號**統計為真**（高波動×當日×隔夜 OOS IC +0.174 / t=7.6，不衰），但**可交易 alpha 主要是漲停鎖死不可成交性的代理**：剔除買不到的漲停股後 OOS 殘餘 +9.1bps / t=0.42（統計為零）。新的高波動 45 檔宇宙**沒有**救起可交易性，反而鎖死更嚴重。故定位為觀察線，不按帳面數字部署。

---

## 1. 訊號定義（凍結）

- **大戶淨買%** =（Σ size×買方主動筆 − Σ size×賣方主動筆，僅計單筆 ≥ 5e6/(close×1000) 張的逐筆）/ 累積總量 × 100。
- TickType：1=買方主動（外盤）、2=賣方主動（內盤）。踩過兩次符號坑，用斷言釘住（見 `finmind-ticktype-sign-test`）。
- 門檻用**固定 500 萬金額**（自適應 P99 過擬，已否決）。
- **PIT**：訊號日 T 只用 date ≤ T 的逐筆累積。
- 標的 = 隔夜跳空 gap =（次日 open_print / 今 close_auc − 1）× 1e4 bps，逐日對宇宙 demean 成剝市場殘差 rgap。

## 2. 宇宙（凍結）

- **高波動篩**：20 日已實現波動 vol20 ≥ ~5%（P60–P80 帶）。理由不是「高波動放大獲利」，而是**訊號 edge 只活在高波動股**——低波動半 net −47bps/日是真金反指標（研究 #1、#13）。
- **真實可交易核心僅 5 檔**（真實往返成本 <25bps、前月量足、頂檔深度 ≥5 口）：光寶科 2301（16.3bps）、華新科 2492（17.8）、穩懋 3105（21.7）、全新 2455（22.1）、威剛 3260（24.2）。
- ⚠️ **tick_bps 跳動代理系統性低估真實價差**（中位 1.88x、最壞 8.9x：景碩 108bps / 台光電 65 / 奇鋐 / 精材 / 環球晶）。任何用 tick_bps 當成本的回測，對這批高價薄約檔的淨值都是假的（研究 #12）。
- 容量牆比價差牆更緊：核心檔頂檔僅 5–14 口，真實容量每檔數口級。

## 3. 驗證過的設計選擇（keep）

| 選擇 | 驗證 | 否決的替代 |
|------|------|-----------|
| **等權** | 研究 #3 | 反波動加權（稀釋 edge） |
| **RAW 訊號**（不做族群中性化當 alpha） | 研究 #2（−8.33bps/t=−2.22） | 族群中性當訊號 |
| **不限族群 tercile** | 研究 #4（去均值後同業不相關 0.03–0.05；跨族群約束零增益） | 跨族群配對（先前錯話已修正） |
| **隔夜（收盤進、隔日開盤出）** | 研究 #5、#11 | 多日持有（lag2 t=0.1）、延後進場（sig(T-1) IC+0.02 null）、盤中 scalp（毛=0） |
| **離散度 ≥ P50 才出手** | 研究 #6（OOS corr t=2.86，資訊擇時非機械放大） | 無條件每日出手 |
| **極端 T4 買單超額加權 + 丟極端賣單** | 研究 #8（控制後 T4 增量 +21.9/t=2.59；賣單零資訊） | 單押 ≥1億 / 納入極端賣 |
| **決策可在 11:00 前鎖定**（訊號 11:00 定形 95%） | 研究 #7 | 等收盤才決 |

- ⚠️ **大戶門檻本身在高波動宇宙無獨立增量**：全體 OFI ≥ 大戶 OFI（OOS IC 0.185 vs 0.167），大戶獨立增量塌到 OOS FM t=1.40（null）；兩訊號 corr 0.87→0.93。**大戶門檻只在一般/低波動宇宙加分**（研究 #10）。高波動核心可省事用全體 OFI。

## 4. 被否決的加法（don't）

- 族群中性化當訊號、反波動加權、跨族群配對、盤中單邊 scalp、冠軍挑戰賽/領先持續性、多日持有、延後進場、加速度因子、T-1 外資/投信/5 日動能/昨日訊號/當沖率、RRG、族群共識、停損/單名封頂/波動目標（削尾同時削 edge）。
- **冠軍挑戰賽**（09:30 起追冠軍、收盤存活者=最後確認）：hold_count 控制 level 後 ex-lock t=−0.79；冠軍 59%/survivor 70% 鎖漲停（基準 5.3% 的 11–13x）；單押收盤冠軍可成交子集 −44.8/t=−1.86 主動賠錢。
- **盤中單邊 scalp**（排名第一×同向大盤×持有 X 分×換手）：tick 級毛報酬即為零（|t|≤1.42），=同邊隨機選檔；同向濾網不加分；換手日燒 270–1844bps。

## 5. 風控（若前瞻測試轉正才啟用）

- **單名部位** ≤ 該腿 1/N 的 1.5 倍（等權，勿讓訊號極端值集中）。
- **單一族群曝險上限**（半導體/電子零組件各設 cap）；或用族群中性訊號**當風控 cap**（研究 #13：maxDD −9% 且不殺 edge，是唯一免費緩解——注意：當訊號用是否決的，當 cap 用才留）。
- **notional ≤ 1/3 帳戶淨值**起步（與 TMF/dayflip-short/momentum-rotation 共用同一份 30 萬保證金、無跨袖協調）。
- 尾部預期：最大回撤 ≈ 40 日 edge、OOS 還 ×3.8；把「八月式 OOS 尾部（maxDD~1500bps、最差 5 日~−620bps）」當**基準情境**而非最壞情境。炸彈是單股/單族群跳空（非大盤，dollar-neutral 抵消市場水位），無法便宜對沖。
- 低波動 regime 濾網是 confound（誠實無前視套用 = 0/43 OOS 日交易），不採用。

## 6. 採納（graduation）門檻

觀察線轉正式採納前必須全過：
1. 前瞻測試累積 ≥ 40 交易日，剔鎖後、扣真實成本、日聚類 t，日均 ≥ +15bps 且勝日 ≥ 60%（40 日 SE≈17bps，故 <15 續命需 t≥1.5 延至 80 日）。
2. 用「延後 N 秒進場」檢定排除 open_print/收盤集合競價的量測偏誤（repo 反覆踩過的坑）。
3. 只在通過真實成本的核心 5 檔上下單。
4. **動能中性化**檢定：已測（2026-09-05，見 §8）——結果=**無獨立可交易 alpha 可畢業**。訊號非動能/波動代理，但正交且買得到的殘差 IC=0，可交易性由漲停鎖死+成本判死；此 gate 事實上無法以帳面 alpha 通過。

## 7. 未結

- 全體 OFI vs 大戶門檻的高低波動配對差樣本力不足（OOS 43 日，t=0.24），需更長樣本定案。

## 8. 動能中性化門已關（2026-09-05）

三支否證同時成立：(1)**非波動代理**（vol20 corr +0.04，加入係數/IC 不動）；(2)**非動能代理**（head-to-head 訊號打贏動能——mom1/mom5/當日日內報酬並列時動能係數全滅、大戶存活 OOS t=3.4）；(3)**但也非獨立可交易 alpha**——訊號與當日價格動作機械同源（corr mom1 +0.69、日內 +0.62），正交殘差**且限定買得到（非鎖死）名單**後 IC=0（IS −0.02/t−0.76、OOS +0.03/t0.87）。帳面 OOS IC +0.173 幾乎全來自「大戶吸貨 ∩ 今日鎖漲停」交集（RAW 五分位持股 47.5% 是鎖死名、鎖死者毛 rgap +146 vs 非鎖死 +58.6）。剔鎖+成本後 RAW/NEUT 五分位十分位 OOS 皆 ≤0。

**含意**：採納 gate §6.4 已解——正確說法不是「連 IC 都是代理」（它打贏動能、與波動無關），而是**訊號與同日價格行動是同一事件兩面，獨立於動能且買得到的增量為零**；可交易性由漲停鎖死+成本判死，與是否獨立無關。**不改變觀察-only 定位，且關掉了唯一可能翻案的門。**
