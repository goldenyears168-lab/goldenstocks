## 訂閱模組後，您將如何付款？

**XQ 目前僅支援信用卡及簽帳卡（帳戶需有足夠金額）扣款，未來不排除會新增其他付款方式。**

**1. 自 3.18.01 版本起，系統已升級為「綠界金流」，可接受之信用卡卡種：**

- 國內外 JCB / VISA / Master / 銀聯卡
- 國內銀行發行之簽帳卡
- 不支援美國運通之信用卡或簽帳卡

**2. 在 3.18.01 版本之前的金流系統可接受之信用卡卡種包括：**

- JCB / VISA / Master / 銀聯卡
- 國內銀行發行之簽帳卡

但若您使用美國運通之信用卡或簽帳卡，或是發生帳戶餘額不足、持卡人發卡銀行不授權之情況時，則簽帳卡將可能有刷不過的情形。

**3. 此外，因金流系統是『每月自動續訂』，故目前暫不支援轉帳、匯款、超商繳費。**
