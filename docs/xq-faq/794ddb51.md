## 安裝XQ的電腦，硬體設備需求為何 ?

【建議電腦配備需求】

最低配備需求：

- **CPU：** Intel Core i7-7700 / **i5-8400 以上**；AMD **Ryzen 5 2600 以上**
- **RAM：** 16GB 以上
- **作業系統：** Windows 11 64-bit

推薦配備需求：

- **CPU：** Intel Core i7-10700 / **i5-12400 以上**；AMD **Ryzen 5 7500F / 7600 以上** (或 Ryzen 7 5700X 以上)
- **RAM：** 32GB 以上
- **作業系統：** Windows 11 64-bit

若是使用筆電，建議要將電源改最佳效能 ( 控制台→系統→電源→一般電源–>切換至最佳效能)。
