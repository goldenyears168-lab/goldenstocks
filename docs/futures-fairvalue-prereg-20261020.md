# 個股期貨「校正合理價」預註冊（2026-10-20）

目的：個股期貨 70–99% 的時間沒成交，最後報價是舊的。用台指期（TXF，ws 逐筆的買一賣一平均）校正，估「現在的合理價」。
定位：**估計現在**，不是預測未來；不是 alpha。只做日盤（09:00:15–13:24）、儀表板 42 檔有期貨者、價格用每股契約價。

## 規格（看結果前先凍結）
- 事件：某檔個股期貨**買賣簿相鄰兩次更新**，間隔 ≥5 秒（歷史報價年齡）。
- 錨價：前一次買賣簿的 (a) 普通中價、(b) micro-price＝`(買一價×賣一量+賣一價×買一量)/(買一量+賣一量)`。
- 目標：下一次買賣簿的**普通中價**（沒有買賣價差彈跳）。
- 校正：`合理價 = 錨價 × exp(β × ln(TX_t / TX_{t0}))`，TX 取買一賣一平均。
- β 三種：(i) 全體依空窗長度分桶（5–10/10–30/30–120/120+ 秒）；(ii) 逐檔；(iii) 逐檔向 (i) 收縮，權重 n/(n+200)。樣本 <100 的檔標「低信心」。
- 對照：融合版（再加現股漲跌，逐檔迴歸）只當參考，不是主規格。
- Kalman 版（2026-10-20 看結果前補登，業界標準骨架，Hasbrouck 1993 的即時版）：狀態 x=ln(有效價)；兩次報價之間 `x += β·ΔlnTX`、方差 `P += q·Δt`；新買賣簿到來以觀測噪音 R 更新（增益 K=P/(P+R)）。觀測用主規格錨價。β 同上（收縮逐檔）；q、R **不調參**，用訓練期事件迴歸 `殘差² = 2R + q·空窗秒數` 的截距與斜率估（q 下限 0）。與簡化版並列，主指標相同；Kalman 勝出才當實作骨架，否則用簡化版。
- **修訂（2026-10-20，第一次 Kalman 失敗後）**：上列迴歸估 q、R 的做法不合文獻標準（R 被空窗事件灌大，狀態過度平滑），結果作廢。改為 Hasbrouck(1993)／Menkveld-Koopman-Lucas(2007) 式狀態空間、**最大概似估計**（預測誤差分解），1 秒網格，無觀測的秒只預測不更新：
  - K1（只用台指）：`x_t = x_{t-1} + β·ΔlnTX + η(q)`；觀測 `買賣簿中價 = x + ε(R)`。參數 β,q,R。
  - K2（加現股）：狀態 [x, b]，b＝期貨減現股的基差（隨機漫步，qb）；額外觀測 `現股價 = x − b + ε(R2)`。參數 β,q,R,qb,R2。
  - 參數用訓練期若干日最大概似估計（逐檔）；訓練期沒資料的檔用已估計檔的中位數並標低信心。
  - 比較對象：不校正(A)、錨價+β(B)、K1、K2；主指標同前。K1 或 K2 若相對 B 的降幅無改善，用 B（或只顯示買賣簿中價）。
  - 已知：台指解釋力在第一次買賣簿檢定僅 1.3%（錨價+β 降幅約 0.6%），此後的修訂是在看過該結果後才做，須視為探索。
- **前向驗證規則（2026-10-20，使用者選 A；看過回測才訂，所以必須用新日盤驗）**：
  - 顯示：平常顯示買賣簿中價；**只有**「自上一次買賣簿更新起，台指大台中價累計變動 ≥4 bps 且空窗 ≥10 秒」才顯示 K2 校正合理價（其餘一律顯示買賣簿中價）。門檻 4 bps 固定，不調。
  - 參數：用 2026-10-19 以前全部資料重估後**凍結**（每檔 K2：β,q,R,qb,R2；訓練資料不足者用已估計檔中位數並標低信心），驗證期間不再更新。
  - 驗證樣本：凍結日之後新日盤，**至少 10 個日盤**（預計 2026-11-03 前後），不得挑日。
  - 通過條件（皆須成立）：① 觸發事件池化 RMSE 相對「買賣簿中價（不校正）」降幅 ≥10%；② 有 ≥30 個觸發事件的檔裡，降幅 >0 的檔數 ≥60%。
  - 未通過：儀表板只顯示買賣簿中價與偏離 bps，不顯示校正合理價。通過才上線，仍標「前向驗證 N 日」。
- 切分：前 14 日估 β，後 14 日驗證。⚠ 後 14 日在 10-20 的第一輪（用成交價當錨）已看過，這輪不算全新樣本。
- 主指標：測試期 RMSE（bps）相對「不校正（錨價）」的降幅。分組：全體；空窗 ≥10s 且 |TX 變動| ≥4 bps。
- 錨價與 β 的主規格 = 訓練期 RMSE 較低者，其餘為次要，**不得事後換主規格**。
- 顯示規則：買賣簿 >30 秒沒更新、TX 斷線、尚無錨價 → 顯示「—」灰色。
- 輸出：合理價；買一／賣一各自偏離合理價的 bps；最新成交價偏離 bps。
- 上線：不設額外門檻；先看主指標是否為正，逐檔不適用者標示。
