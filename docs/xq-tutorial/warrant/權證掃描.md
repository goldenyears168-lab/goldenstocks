# 權證掃描 掌握大戶進出

###### 2016-04-14 13:35:48

複製連結

[![9_01](../images/1e16a6a386.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/9_01.png)大家都知道權證有以小博大的特性, 對小資族很有吸引力, 但真要在權證上賺到錢, 還挺難的。 俗話說的好, 工欲善其事, 必先利其器, 所以找到有利的交易工具, 賺錢的機會就變大了。 而XQ權證策略, 正好提供多種尋找適合交易權證的方式, 接下來就讓我們逐一來瞭解看看吧! 這次我們先介紹[權證掃描]這個工具。這個工具最重要的功能是幫我們在茫茫股海中, 快速找出目前市場大戶正在進出的權證有什麼。從XQ策略->權證策略->可開啟[權證掃描]頁面。 [![20160111-01](../images/9b6d760ed8.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-01.png)要怎麼看呢? 首先, 可以看這些大單是不是有連續買進或賣出特定某檔股票的權證, 是買權還是賣權? 然後去看現股是不是也動了, 之後就可以決定是要去追現股還是跟進權證了。 您說這樣是不是可以很快抓住市場脈動, 跟進賺錢的腳步呢? [![20160111-02](../images/3d0e4a9686.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-02.jpg)再來說說怎麼操作吧! 在XQ [權證掃描]頁面左上方, 有〝單筆成交金額〞過濾選項, 我們可以選擇不同金額, 查看一般大單or特別大單進出情形。 [![20160111-03](../images/6c779e5f61.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-03.jpg)右上方則提供〝權證類型〞選擇, 我們可以分開查看都是哪些〝買權〞or〝賣權〞被「買進」or「賣出」。至於要怎麼看大戶是「買進」還是「賣出」呢? 看報價〝單量〞的顏色就可以了, 紅色為買進, 綠色為賣出。 [![20160111-04](../images/c3875c42d6.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-04.jpg)因為很多人想知道大戶買了哪些權證? 賣了哪些權證? 是何時進場的? 又是何時出場的? 所以XQ [權證掃描] 還有提供進階設定功能, 設定按鈕就是頁面左上方的漏斗。 [![20160111-05](../images/a045161765.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-05.jpg)若您想知道大戶都在買什麼, 內外盤設定就選〝外盤〞, 因為外盤為追價買進成交的結果；反之〝內盤〞為殺出的結果。 [![20160111-06](../images/f7562dc90d.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-06.jpg)[![20160111-07](../images/3635141cf4.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-07.jpg)若您想知道大戶對某檔股票的權證現在是買進還是賣出, 就設單一標的股, 這樣用起來就像查同標的明細進出, 很快就能找到那些同秒掃貨or出貨的大戶交易了。 [![20160111-08](../images/3b0809f57e.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-08.jpg)[![20160111-09](../images/9c606bd418.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111-09.jpg)有了工具做交易, 是不是覺得交易變簡單了, 賺錢的機會也來了!
