# 以股追權 挑對股票再出手

###### 2016-04-14 13:37:24

複製連結

[![9_03](../images/932eded893.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/9_03.png)交易權證, 想賺錢, 首要會挑標的股。 因為權證是跟著標的股在漲跌的, 所以當股票有大漲大跌行情要發生時, 才進場買認購或認售, 這樣才有機會賺到錢, 享受搭順風車, 以小搏大的快感!! [以股追權]這個單元, 主要就是提供各種選股訊號。 XQ以最新的雲端選股系統, 除了提供預設的權證策略訊號外, 亦提供使用者自設的XS警示訊號, 投資人只要點選訊號來源設定, 進行勾選就可以了。 另外, 相關權證區同步提供的標的權證報價, 讓投資人於盤中訊號出現時, 就可即時決定是要交易股票還是權證了。 [![20160118-01](../images/6e9b1b6b2e.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118-01.png)還有, 右上角提供的標的走勢區, 除了可與左側行情商品連動外, 亦可自行切換商品, 所以盤中若有聽到什麼馬路消息, 也可立刻查看是否值得投資喔!!
