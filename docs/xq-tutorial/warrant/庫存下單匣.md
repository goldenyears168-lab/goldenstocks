# 庫存下單匣

###### 2016-04-14 13:39:34

複製連結

[![9_06](../images/847446bfbc.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/9_06.png)「交易‧創造自己的聖盃」作者凡‧沙普認為: 進場與選股是不重要的, 出場才是輸贏的關鍵。為此, 他作了一個「丟銅板」交易系統, 以證明隨機進場, 加上好的出場策略, 這樣也能賺錢。 所以, 當大家帳上已有權證庫存後, 接下來除了要有擬定好的出場策略外, 就是需要有果斷的執行力, 及一套好用的下單介面了。 以下, 就由小編來跟大家介紹[權證庫存下單匣]提供的各項功能吧!!

- 群組管理:
權證庫存資料會依照標的股分類。左側列表, 依標的股代碼排序顯示。右側庫存, 依點選標的股及權證類型顯示。 [![20160118a-01](../images/a79dd50d77.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118a-01.png)當庫存標的太多時, 可輸入關鍵字進行搜尋。 [![20160118a-02](../images/33cce70943.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118a-02.png)

- 即時報價:
庫存下單匣, 同時提供標的股與庫存權證報價, 方便投資人即時掌握價格變動, 以判定是否要下單。 庫存區下方, 另提供投資人可同時觀察五支權證五檔報價。 [![20160118a-03](../images/5d24cb5756.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118a-03.png)

- 快速改價量:
下單匣, 除提供投資人可由下拉選項, 及即時報價區點選報價, 改變各別價格外, 亦提供統一改變所有價位快速鍵 (買進價/賣出價/成交價)。 張數部分, 亦可點選下拉選項, 及可下單餘額進行更改。 [![20160118a-04](../images/a00ff1f7e9.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118a-04.png)

- 快速下單:
投資人除了一檔一檔下單, 亦可選擇依勾選或是全選送單。 [![20160118a-05](../images/e5429b2111.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118a-05.png)若此時, 看到標的股價格有異動, 想下單, 亦可由左側標的名稱右鍵, 點選買進或是賣出。 [![20160118a-06](../images/01d87128d5.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160118a-06.png)希望權證庫存下單匣的功能大家會喜歡，如果有任何建議的話也請跟我們分享，在此, 祝大家投資順利, 荷包賺飽飽!!
