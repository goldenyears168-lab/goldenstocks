# 權證下單匣

###### 2016-04-14 13:38:41

複製連結

[![9_05](../images/7cb233d966.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/9_05.png)在「相關權證區」右上角還有兩個下單按鈕, 一為『勾選下單』, 另一為『最佳下單』。先跟大家介紹XQ獨家提供的『最佳下單』功能。 [![20160111b-01](../images/5c5531f7e0.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111b-01.jpg)『最佳下單』設計目的: (1) 風險考量。當我們只選1檔權證下單時, 可能會碰到流動性不足或買賣價差大, 獲利被吃掉情形；所以XQ『最佳下單』提供權證篩選功能, 讓系統幫我們快速選出多檔適合交易的權證, 以達風險分散效果。 (2) 資金配置。XQ『最佳下單』可以設定每次權證交易總下單金額, 然後系統會依照我們的設定自動配置每筆權證下單金額, 以達到依標的股票來配置資金的效果。 簡言之, 點選『最佳下單』-> 系統將『相關權證設定』及『最佳下單設定』篩選出來的權證, 依最佳下單〝金額與排序〞設定, 自動計算勾選符合下單條件商品。 如果大家還不是很懂, 小編再分解說明一下: 首先, 下單匣依下單排序選擇顯示符合篩選條件商品, 再來, 系統在使用者沒有設定每筆金額時, 各商品價量會帶第1委賣價&量, 若有設每筆金額, 則各商品依第1委賣價及此金額計算張數, 張數最多等於第1委賣量, 然後, 系統由上至下勾選金額加總等於下單設定總金額商品, 而最後1檔商品張數依各商品加總剩下的金額計算。 [![20160111b-02](../images/f4e3ad10de.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111b-02.jpg)看完小編的補充說明, 大家有沒有覺得『最佳下單』這個功能很強啊!! 接下來我們來看『最佳下單設定』吧!! 『最佳下單設定』除了提供跟下單有關的權證進階篩選條件外, 還提供下單金額設定及下單排序選擇功能。因這裡的下單排序方式與系統勾選商品次序有關, 故大家在使用時, 記得先確認您想依哪個下單條件, 大到小or小到大排序喔!! [![20160111b-03](../images/df138d8be0.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111b-03.jpg)『最佳下單設定』有兩項大家比較不認識的條件, 小編在此跟大家說明一下!! 1.「預估報酬率」: 在計算標的股漲跌1%, 權證持有10天, 預估報酬結果。 數值越大, 賺錢機會越大。系統預設是依此條件, 大到小排序&勾選商品。 2.「Theta權證比」: 在計算Theta/權證價格年化值。 因每檔權證價內外程度與離到期日時間長短不同, 價格與Theta值差異大, 故統一計算年化值, 比較基礎才一致。通常越價外, 此數值越高；越價內, 數值越低。離到期日越遠, 數值越低；離到期日越近, 數值越高。若想賺錢, 此數值要越低越好。 除了最佳下單之外，你也可以自己手動勾選有興趣的權證。只要在權證商品名稱之前打勾，然後點選勾選下單，被選到的商品也會被送到下單匣內。 [![20160111b-04](../images/5caafec553.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111b-04.jpg)

## 下單匣的操作

在下單匣內, 若您是要立刻下單, 可點選「勾選送出」將下單匣內所有已勾選商品, 一同送出下單；或是針對單一商品點選「送出」下單。若您還有需要調整價格、張數, 您除了可從畫面上提供的價格、張數選擇進行調整外, 還可以使用〝委託幫手〞再操作看看喔!!
