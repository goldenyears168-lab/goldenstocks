# 以權追股 透視多空標的

###### 2016-04-14 13:36:30

複製連結

**[![9_02](../images/28c796b40b.png)](https://www.xq.com.tw/wp-content/uploads/2016/01/9_02.png)**股市瞬息萬變, 行情起起落落, 多空消息真真假假, 唯有真槍銀彈不騙人。XQ[以權追股]將金錢進出計算結果, 以即時揭露方式, 讓市場資金無所遁形, 而我們要做的只是決定是否跟進就可以了。 交易不外乎決定做多或做空, 做多什麼? 做空什麼? 何時進場? 何時出場? 首要決定在交易標的。而XQ[以權追股]這個工具就是在提供主力資金進出標的訊息。有了主力進出多空標的及時間, 交易就簡單了。至於那些主力是波段單, 那些主力是隔日沖單, 這以後我們再教大家從券商歷史進出去看。今天就先來介紹[以權追股]這個盤中資訊吧! 從XQ->策略->權證策略->開啟[以權追股] [![20160111a-01](../images/db661e2c13.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-01.jpg)XQ[以權追股]主要提供兩種標的訊息, 一為[極短線主力進出], 提供多空標的每秒買賣金額統計, 另一為[主力進出], 提供多空標的當日累計買賣金額統計。 [![20160111a-02](../images/93fa5fcabf.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-02.jpg)[![20160111a-03](../images/91551aa43a.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-03.jpg)[極短線主力進出]為上次介紹的[權證掃描]延伸, 多空標的依買進認購(Buy Call), 賣出認購(Sell Call), 買進認售(Buy Put), 賣出認售(Sell Put), 分開顯示。主力在做多時, 除了買進認購(Buy Call)外, 通常還會賣出認售(Sell Put), 所以我們在看[極短線主力進出]時, 可以單獨看多(B/C), 多(S/P), 或合起來看多(B/C+S/P)。反之, 做空則看空(B/P), 空(S/C), 或空(B/P+S/C)。 [![20160111a-04](../images/8af6b69eb4.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-04.jpg)[![20160111a-05](../images/78849fd388.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-05.jpg)[極短線主力進出]與[權證掃描]用法相同, 可以看主力是不是有連續買進或賣出特定某檔股票權證, 然後看現股是不是動了, 之後再決定要去追現股還是權證。 [![20160111a-06](../images/2c017b625f.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-06.jpg)[極短線主力進出]與[權證掃描]一樣有提供金額過濾及標的股篩選功能, 下個版本我們將會提供單一標的股篩選功能, 敬請期待。 [![20160111a-07](../images/2f0204705d.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-07.jpg)[主力進出]則為[極短線主力進出]的延伸, 多空標的依權證做多(B/C+S/P),做空(B/P+S/C)金額累計。這頁除了提供全部排行外, 也提供剔除50權值股排行。 [![20160111a-08](../images/2146b99328.jpg)](https://www.xq.com.tw/wp-content/uploads/2016/01/20160111a-08.jpg)[主力進出]與[極短線主力進出]及[權證掃描], 三者如同母子關係: [權證掃描]是孩子, 提供每筆大單明細, 彙整變成[極短線主力進出], 再彙整變成[主力進出]。所以, 若您想知道目前市場多空角力的結果, 就看[主力進出]；若想知道每秒大單合計的結果, 就看[極短線主力進出]；若每筆大單成交的情形都想知道, 就看[權證掃描]吧! 至於權證該怎麼選? 畫面下方[相關權證區]有提供多種權證篩選設定及欄位排序方式。過濾條件如: 發行券商設定, 只挑口碑好的券商；欄位排序如: 依預估報酬率排序,…。這部分與下單有關, 我們就留待下次再跟大家介紹囉！
