# 工具列/選單/狀態列：支援調整大小

###### 2022-05-16 18:47:30

複製連結

在使用XQ時，有時後會因為選單、工具列、以及下方的狀態列無法調整，讓整個介面會因為過大或過小而操作不順。

這次改版，我們提供大家可以自由調整這三個地方的大小，大家可以在上面工具列的右鍵選單中選擇「工具列顯示設定...」，就可以叫出設定介面。

[![](images/b3aff05bc8.png)](https://www.xq.com.tw/wp-content/uploads/2022/05/2022-05-16_18-55-11.png)

如果修改後，覺得要恢復成系統出廠時的預設大小，也可以點擊設定下方「套用系統預設大小」就可以恢復！是不是很方便呢！

[![](images/c8d9a757de.png)](https://www.xq.com.tw/wp-content/uploads/2022/05/2022-05-16_18-47-25.png)
