# 如何新增警示條件？

新版的雲端監控 (個人版 3.07, 企業版 7.07 後)，除了可以監控單一商品之外，同時也新增了針對清單以及庫存的監控功能。 

## #單一商品設定畫面介紹

監控單一商品的流程跟先前版本類似，使用者輸入商品代碼，然後挑選想要監控的條件。 [![](../images/144c16f255.png)](https://www.xq.com.tw/wp-content/uploads/2022/01/雲端單01.png) [![](../images/8fdee5eab0.png)](https://www.xq.com.tw/wp-content/uploads/2022/01/雲端單02.png) 此次改版，新增了更多的監控條件，可以點擊條件分類來瀏覽。點擊條件方框即可加入此條件。部分條件可以設定參數，在條件框上會有文字提示，點擊後可以輸入參數。 [![](../images/3cfbff648a.png)](https://www.xq.com.tw/wp-content/uploads/2022/01/雲端單03.png) [![](../images/4fc96740a7.png)](https://www.xq.com.tw/wp-content/uploads/2022/01/雲端單04.png) 

## # 清單監控設定畫面介紹

如果用戶希望可以針對一個清單內的所有商品同時進行監控的話，例如我某一組自選股內任一商品上漲2％時通知我，就可以使用清單監控功能。 清單監控功能的基本觀念，是把監控的範圍分成多個「監控區」，使用者可以針對每個監控區，放入「要監控的清單」，以及「要監控的條件」，當清單內的任一商品符合指定條件時，系統就會產生通知，而且當清單內的商品有異動時，新加入的商品也會自動被監控。每個監控區可以放入多個清單，方便使用者用一樣的邏輯來監控不同的商品來源。 首先，使用者選擇監控區，然後加入要監控的清單。可以監控的清單包含：

- 自選股組合
- 自動選股清單，包括：

- XS每日選股清單
- 籌碼高手每日選股清單
- 贏家選股策略每日清單
- 嘉實投顧的個股展望清單
 選擇好清單之後，就可以設定需要監控的條件。 清單監控支援的條件與個股監控類似，使用者可以切換條件分類，然後點擊要加入的條件方框。 [![](../images/c3d3d34003.png)](https://www.xq.com.tw/wp-content/uploads/2022/01/雲端清01.png)

## #庫存監控設定畫面介紹

除了可以針對指定清單內的商品進行監控之外，使用者也可以使用庫存監控功能來監控交易帳號內的庫存商品。 使用的方式類似清單監控，系統提供多個庫存監控區。使用者可以針對每個庫存監控區，放入「要監控的交易帳號」，以及「要監控的條件」，當被監控帳號內的任一庫存商品符合指定條件時，系統就會產生通知。同樣的，如果被監控的交易帳號的庫存商品在盤中發生異動時(例如使用者透過這個帳號買入了一檔新的商品)，這個新加入的商品也會自動被監控。每個庫存監控區可以放入多個帳號，讓使用者可以用一樣的邏輯來監控不同帳號的庫存商品。 支援的庫存帳號有以下限制：

- 支援XQTrade的所有證券帳號，包含模擬交易證券帳號，也就是說庫存監控只支援台股股票商品， 每日開盤前會更新監控帳號的庫存商品，確認監控的範圍。盤中收到成交回報後，會自動更新監控商品(更新間隔約30秒)
 可以針對帳號內的全部庫存商品進行監控，也可以只監控做多的商品，或是只監控做空的商品。也可以點擊右上角的「設定交易帳號」按鈕，登入更多的交易帳號。 設定監控條件的方式與清單監控相同，一樣是點擊條件方框就可以加入。 [![](../images/a61e2bf1f5.png)](https://www.xq.com.tw/wp-content/uploads/2022/01/雲端庫01.png)
