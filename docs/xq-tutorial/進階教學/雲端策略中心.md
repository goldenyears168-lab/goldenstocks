# 雲端策略中心

###### 2016-04-14 15:40:23

複製連結

[![XQ雲端策略中心](../images/b97f515fbe.png)](https://www.xq.com.tw/wp-content/uploads/2016/04/XQ雲端策略中心.png)今天小編要來介紹雲端策略中心的全新樣貌，雲端策略中心換上新衣，有沒有覺得煥然一新呢! 話不多說，小編趕快帶大家認識新版的雲端策略中心。

### ●首頁

雲端策略中心首頁，將策略區分為多、空兩種，在多、空分類下，依照策略屬性不同，策略共分為短線、中線、長線三種，讓使用者可以依照自己的投資習性，去尋找對應的相關策略。 [![雲端策略中心_首頁](../images/55b2f95bf4.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/雲端策略中心_首頁.png)在首頁，每個策略會顯示其勝率、總報酬率、平均報酬率的資訊，以★作為評分的標準，★越多表示分數越高，並依照勝率的高低進行策略排名。 由於首頁的排名只有列出策略區間的前十名，如果想要看到策略區間的所有策略數值，這時候可以點選標題右邊的「看更多」。 [![雲端策略中心_首頁看更多](../images/d987f89e7c.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/雲端策略中心_首頁看更多.png) 這邊將會列出所選擇的策略區間內所有策略，跟這些策略的回測數值資訊。 小編另外提供二項小技巧 技巧1：這邊的區間設定是可以依照需求自由勾選的，不須要回到上一頁點選「看更多」。 技巧2：勝率、總報酬率、平均報酬率、訂閱狀態的欄位有提供排序功能喔!! [![雲端策略中心_全部策略](../images/f3211c65b6.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/雲端策略中心_全部策略.png) 

### ●策略內容

介紹完首頁的功能後，可別以為這樣就結束了，小編要接下去講解策略內容頁的新內容。 雲端策略中心的內容說明頁在新版2.30的XQ中，將策略說明改成簡短的講解，新增了策略的回測報告，希望藉由回測報告提供的歷史回測數據，讓各位用戶可以知道此策略過往的績效表現，增添在投資的決策上的判斷資訊。 [![雲端策略中心_回測報告](../images/15ab893b87.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/雲端策略中心_回測報告.png)見上圖，策略內容分為回測報告、回測設定兩個頁面。 1.回測報告頁面主要分為兩個區塊。 紅框1：頁面上方會說明此策略的投資概念。 紅框2：會顯示此策略的回測統計數值，並依照策略的短、中、長分類，而有不同的回測區間可供選擇。 2.回測設定頁面主要提供進場條件、出場條件、選股條件、交易設定 4種內容。 [![雲端策略中心_回測設定](../images/e3bca9b355.png)](https://www.xq.com.tw/wp-content/uploads/2017/07/雲端策略中心_回測設定-1.png)以上為新的雲端策略中心的新貌，除了以上的更新外，這次XQ小組特別將所有的策略重新改寫過，以更嚴謹的角度做出發，提供更為貼近策略想法的腳本，配合新增回測的相關資訊，希望未來在使用策略中心時能夠更便利。 由於有許多用戶對舊版的策略非常喜愛，小編在這邊特別提供舊版的策略，讓有需要的用戶能夠自行下載使用。 [點我下載策略](https://www.xq.com.tw/dl/xs/%E9%9B%B2%E7%AB%AF%E7%AD%96%E7%95%A5%E4%B8%AD%E5%BF%83(%E8%88%8A%E7%89%88).DSRX)
