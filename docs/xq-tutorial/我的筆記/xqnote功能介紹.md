# XQNote功能介紹

###### 2018-07-04 15:28:03

複製連結

### [![XQNote功能介紹](../images/b7d367a5e6.png)](https://www.xq.com.tw/wp-content/uploads/2018/07/XQNote.png)

XQNote提供了網路書籤、文章筆記、段落筆記、畫面裁剪、編輯暫存及儲存檔案等功能，下列一一介紹： [![](../images/f190f22a17.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step01@2x-1.jpg) 

### 網路書籤

截取網頁內容，將不要的廣告內容濾掉，保留自己想看的文章精華，再寫上心得筆記，加上標籤為資料分類及指定存放位置，方便以後查詢，另外，我們也保留了原來的網頁連結，方便以後再度造訪該網頁。 [![](../images/6f44e743a6.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step02@2x.jpg)

### 文章筆記

跟”網路書籤”一樣，不同的是，文章筆記，可以在內文下方，再加上不同網頁的內容，一篇文章筆記，可以來自不同網頁、及不同時間點的結合。下列為儲存時，可以選擇＂加到現有筆記＂的畫面： [![](../images/997ee499ac.png)](https://www.xq.com.tw/wp-content/uploads/2018/07/step10@2x.png) 

### 段落筆記

文章不想整篇存起來，想單獨儲存片段精采內容，您可以利用＂段落筆記＂功能，記錄您要的片段內容。[![](../images/5f34cee7cc.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step03@2x.jpg)

### 畫面裁剪

有時重要的資訊除了文字內容外，還需要結合畫面，這樣才能完整將訊息保留下方，＂畫面裁剪＂提供了此功能，您可以輕鬆地抓取任何網頁畫面。[![](../images/5460371f3b.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step04@2x.jpg)

### 編輯暫存

您想利用多篇文章，編輯同一個主題內容嗎？＂編輯暫存＂可幫助您隨時隨地將要的段落暫存在同一個地方，等您收集完成，再一起編排。目前可存20段文章。**[![](../images/e83704bf9f.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step05@2x.jpg)**

### 儲存檔案

網頁的檔案內容，可以輕易的存下來，目前支援PDF、PNG、JPG、GIF。 [![](../images/f065c8b3ca.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step09@2x.jpg)
