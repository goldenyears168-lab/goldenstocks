# Chrome外掛程式怎麼使用？

###### 2018-07-31 17:12:19

複製連結

[![Chrome外掛程式怎麼使用](../images/769e30e4a9.png)](https://www.xq.com.tw/wp-content/uploads/2018/07/外掛程式怎麼使用.png)除了可以從XQ內，把畫面中的圖表存到「我的筆記」之外，如果您使用Chrome瀏覽器，也可以透過我們提供的XQNote外掛程式，把網頁內容存到「我的筆記」內。 首先您要先開啟Chrome瀏覽器，然後點選這個[下載網址](https://chrome.google.com/webstore/detail/xqnote/eejbijlejhbapneabiklcpfoflikpdmb?hl=zh-TW)，在下列畫面點選＂加到CHROME＂按鈕，就可以將XQNote程式加入Chrome擴充功能。 [![](../images/c4d848d6a2.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step11@2x-1.jpg) 安裝完成之後，就可以在Chrome的瀏覽列上面看到XQNote的按鈕。XQNote提供了網路書籤、文章筆記、段落筆記、畫面裁剪、編輯暫存及儲存檔案等功能，可以快速地將瀏覽器內的網頁內容儲存到「我的筆記」內。 步驟一：在您瀏覽的網頁右上方，點選XQNote按鈕，例如選擇＂網路書籤＂方式儲存資料 [![XQNote](../images/be799e9bdc.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step01@2x.jpg) 步驟二：XQNote將您要儲存的網頁，把文章內容抓進來，您可以由此編修內容。 [![](../images/6f44e743a6.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step02@2x.jpg)步驟三： 可以將您保存的內容作標籤分類及指定存放位置，您也可以在此寫心得內容，以方便日後查看。 [![](../images/1be4a55895.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step07@2x.jpg)步驟四： 保存的內容，可前住［XQ全球贏家／我的筆記］查看內容。 [![](../images/5e0f5cc5ef.jpg)](https://www.xq.com.tw/wp-content/uploads/2018/07/step08@2x-2.jpg) 請點選［[XQNote功能介紹](https://www.xq.com.tw/LessonPreview.aspx?p=4974&post_type=tutorial&preview=true)］，有完整功能說明。
