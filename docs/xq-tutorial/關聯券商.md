# 關聯券商

###### 2022-09-22 18:24:57

複製連結

XQ獨創「關聯券商」功能 ！ 在之前的教學文章介紹提到，股價要有行情，各方勢力的追捧是一個關鍵要素。將各方勢力歸納為五大派：1 公司派、2 內部人、3 法人、4 官股券商、5 大戶。公司派勢力一般由庫藏股分點找到關鍵券商，但對於沒有實施庫藏股的公司而言，無從了解公司派大股東的想法。 對此，XQ提出「關聯券商」功能，藉由分析歷年主力券商資料，找出大戶持股異動關聯的券商，系統將其預設為該個股的關聯券商屬性。操作方式如同關鍵券商功能，可視為觀察籌碼進出及選股之參考工具。 由於大多數投資人在進入股市的入門學習工具通常是技術指標，然而K棒是結果，XQ不斷創新嘗試提供更多有用的工具協助投資人從多面向掌握推動K棒背後的原因，關聯券商功能即是籌碼分析的新工具之一。在分析關聯券商資料的過程中，成功的案例告訴我們，當個股關聯券商有交易異常現象，背後也許有值得投資人挖掘的原因，可再搭配產業趨勢、公司財報、 題材、法人籌碼等多項工具研究，粗中取精，有機會乘坐在高手分點的肩膀上找到值得投資的成長股。 以下列出關聯券商的相關應用。
